# 화면 문구 점검

## 순서
1. 문구를 화면별로 묶고, 한 줄씩 `references/word-list.md`의 금지어와 바꿀 말을 대 봐요.
2. 버튼은 동사로 끝나는지(예: 저장하기, 보내기) 봐요.
3. 오류 메시지는 무엇이 잘못됐는지와 고객이 할 일을 둘 다 말하는지 봐요.
4. 고친 문구는 원래 문구 옆에 두고, 왜 고쳤는지 한 줄을 붙여요.

## 판단 기준
- 해요체, 능동문.
- 고객 탓으로 들리는 말(잘못 입력하셨습니다)은 피하고, 할 일을 말해요(숫자만 넣어 주세요).
- 같은 뜻에는 화면마다 같은 말을 써요.
