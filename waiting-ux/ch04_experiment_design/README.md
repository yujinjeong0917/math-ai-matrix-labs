네 가지 대기 화면(빈 화면, 스피너, 진행 막대, 스켈레톤)을 한 사람이 모두 보는 가상 실험의 순서를 균형 라틴 방격으로 배정하고, 기대 효과 크기에서 한 집단당 인원을 계산한다. 모든 숫자는 가상, 예시용이다.

- 실행: `python3 experiment_design.py`, 테스트: `python3 -m unittest -v`

손계산(d=0.4, 알파 0.05, 검정력 0.80): (1.960+0.842)/0.4=7.005, 제곱 49.07, ×2=98.1, 보정 1.96²/4=0.96, 합 99.1을 올림해 100명.

기대 출력은 `python3 experiment_design.py`로 확인한다(순서표 4줄, 쌍 12가지 각 1번, 시드 7 배정 8명, d별 인원 394/100/64/26/23(d=0.85), 2×2 칸당 100명이면 400명, 비교 6쌍 본페로니 보정 154명, 검정력 0.81과 0.52).

출력 번호는 [1]부터 [9]까지이다: `[6]` 검정력(알파 0.05), `[7]` 303명 중 63명 제외 = 20.8%, `[8]` z 합 2.802, `[9]` 8명 배정이면 빈 화면이 위치별로 2, 2, 2, 2번, 10명이면 2, 3, 3, 2번(4의 배수가 아니면 위치 균형이 깨진다).

인원 계산(`n_per_group`)은 서로 다른 사람 두 집단의 평균을 비교하는 집단 간 설계의 근사식이다. 한 사람이 네 화면을 모두 보는 집단 내 설계의 인원은 계산하지 않는다. 순서 배정(균형 라틴 방격)은 집단 내 설계에서 쓴다.

확인하지 못하는 것: 정규 근사식이라 정확한 값은 G*Power 같은 도구로 확인해야 한다. 홀수 조건은 지원하지 않는다. 반복 측정에서 앞 조건이 뒤 조건에 남기는 영향(이월 효과)이 사라지는지는 보장하지 않는다. 집단 내 설계의 인원 계산은 다루지 않는다.
