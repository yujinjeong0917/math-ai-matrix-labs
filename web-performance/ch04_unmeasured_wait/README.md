# 4장 실습: 지표 밖 대기와 고전 논문 숫자 맞춰 보기

가상 결제 흐름에서 세 지표 밖의 시간 비율을 구하고, Harrison 외(2010)와 Myers(1985)의 숫자를 손계산과 맞춘다. 결제 흐름의 시간은 가상, 예시용이고 논문 값은 열람한 저자 공개본에 적힌 것만 쓴다.

- 실행: `python3 unmeasured_wait.py`, 테스트: `python3 -m unittest -v` (표준 라이브러리만, 난수 없음)
- 기준값 출처: web.dev 문서(2026-11-20 확인, 정리해서 옮김, 문장 인용 아님). 4장의 논문 값은 저자 공개본 PDF(2026-11-20 확인).

손계산: 5.61/5 = 1.122(12.2%), 16.75/15 = 1.1167(11.7%). 쌍 비교 예 (16-6)/40 = 0.25. Myers의 1~17초 균등분포 평균 (1+17)/2 = 9초, 논문의 경험적 평균 8.601초. 86.1% x 48명 = 41.33명으로 정수가 아니고 41/48 = 85.4%, 42/48 = 87.5%이며 분모 48 이하에서 86.1%가 되는 쌍은 31/36뿐이다. 결제 흐름 60+6000 = 6060ms 중 6000/6060 = 99.0%가 세 지표 밖이다.

기대 출력:
```
[Harrison] 기준 5초 막대와 같게 느껴진 리브 막대 5.61초: 5.61/5 = 1.122, 증가율 12.2%(논문 표기 12.2%), 차이 0.61초
[Harrison] 기준 15초 막대와 같게 느껴진 리브 막대 16.75초: 16.75/15 = 1.1167, 증가율 11.7%(논문 표기 11.7%), 차이 1.75초
[Harrison 쌍 비교 예] 16번, 6번, 18번, 합 40번: 선호 점수 (16-6)/40 = 0.25
[Myers] 변동 지연 1~17초 균등분포의 평균 9.0초, 논문의 경험적 평균 8.601초, 차이 0.399초
[Myers] 86.1% x 48명 = 41.33명, 41/48 = 85.4%, 42/48 = 87.5%
[Myers] 분모 48 이하에서 86.1%가 되는 (분자, 분모): [(31, 36)]
[Myers pr] {'진행 표시 유무': 0.0006, '변동성 지각(진행 표시 있을 때)': 0.0011, '일정 대 변동(진행 표시 없는 버전)': 0.1497}
[하지 않을 곱셈] 6초 x 11.7% = 0.7초: 5초와 15초에서만 쟀으므로 이 값은 근거가 없다
[점검 3] 탭 100ms, 대기 4000ms: 세 지표 밖 4000/4100 = 97.6%
[결제 흐름] 전체 6060ms 중 세 지표 밖 6000ms = 99.0%
```

확인하지 못하는 것: Harrison의 값은 같게 느끼는 길이이고 만족도가 아니며 5초와 15초 막대에서 두 막대를 비교한 결과다. Myers의 값은 느낌 점수와 선호이고 행동이 아니다. 표 값과 그림 속 값, Myers의 일정과 변동 지연 전체 비교 p값은 읽지 못했다. 86.1%의 분모는 원문으로 확인해야 한다. 사람이 느낀 시간은 계산하지 않는다.
