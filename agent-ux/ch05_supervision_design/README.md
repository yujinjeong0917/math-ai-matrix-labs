# 5장 실습: 감독 화면 점검과 비교 설계 계산

위험과 정답 여부 교차표로 두 요인이 섞였는지 보고, 가상 감독 기록 24단계에서 잡은 비율, 괜히 멈춘 비율, 판단이 맞은 비율을 센다. 화면 점검표 네 항목도 확인한다. 모든 숫자는 가상, 예시용이거나 논문 보고값이다.

- 실행: `python3 supervision_design.py`, 테스트: `python3 -m unittest -v`
- 출처: He 외(2025)의 과제 구성 서술(위험 높은 과제 1~3은 모두 불완전한 계획, 낮은 과제 4~6은 모두 정확한 계획)을 옮겼다. doi.org/10.1145/3706598.3713218

기대 출력:
```
[1] He 외 과제 구성(서술 옮김) 교차표 (위험, 계획이 맞음): 낮음/맞음=3, 낮음/틀림=0, 높음/맞음=0, 높음/틀림=3
  빈 칸 2개, 균형 아니요
  칸당 6단계 설계: 합 24단계, 빈 칸 0개, 균형 예
[2] 가상 감독 기록(24단계)
  화면 P: 오류 12단계 중 잡음 8(66.7%), 맞은 12단계 중 괜히 멈춤 3(25.0%), 판단이 맞은 비율 70.8%
  화면 Q: 오류 12단계 중 잡음 3(25.0%), 맞은 12단계 중 괜히 멈춤 0(0.0%), 판단이 맞은 비율 62.5%
  화면 P를 위험별로 보면 잡은 비율 낮음 50.0%, 높음 83.3%
[3] 화면 점검표(팀 한계 5초, 가상)
  초안(중간 수준 화면): 1/4 통과, 미통과 = 가장 긴 조용한 구간이 팀 한계 이하, 긴 단계 중 멈추기 버튼이 있음, 되돌릴 수 없는 단계 앞에 확인이 있음
  고친 화면: 4/4 통과, 미통과 = 없음
```

확인하지 못하는 것: 기록과 화면 값은 가상이고 어느 화면이 낫다는 근거가 아니다. 점검표의 한계값(5초)은 팀이 정하는 값이며 논문 근거가 없다. 인원 계산은 다루지 않는다.
