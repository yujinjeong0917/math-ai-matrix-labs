# 0장 실습: 정보 수준별로 화면이 바뀌는 시각 세기

가상 환불 에이전트가 20초 동안 일하는 진행 화면에서, Yu 외(2025)의 세 정보 수준(높음 10항목, 중간 3항목, 낮음 1항목)별로 화면이 바뀌는 시각과 가장 긴 조용한 구간을 센다. Yu 외 표 1의 평균 차이와 선호 인원도 다시 계산한다. 시각과 항목 대응은 이 장이 정한 가상 값이다. 모든 숫자는 가상, 예시용이거나 논문 보고값이다.

- 실행: `python3 progress_levels.py`, 테스트: `python3 -m unittest -v`
- 출처: doi.org/10.1145/3715070.3749256 (포스터, 본문 열람 2026-11-16과 11-17, 서지 확인 2026-11-20). Yu 외의 값은 표 1의 보고값이다.

기대 출력:
```
[1] 가상 환불 한 건 20초, 단계 6개
  접수 해석 0~2초
  주문 조회 2~5초
  규정 확인 5~9초
  환불 지급 9~15초
  고객 안내 15~17초
  기록 17~20초
[2] 정보 수준별 화면
  높음: 항목 10개, 바뀌는 시각 10곳(0,1,2,4,5,8,9,15,17,20초), 가장 긴 조용한 구간 6초(9초~15초, 환불 지급)
  중간: 항목 3개, 바뀌는 시각 7곳(0,2,5,9,15,17,20초), 가장 긴 조용한 구간 6초(9초~15초, 환불 지급)
  낮음: 항목 1개, 바뀌는 시각 1곳(20초), 가장 긴 조용한 구간 20초(0초~20초, 여러 단계)
[3] 환불 지급 중 12초에 문구를 하나 더하면 가장 긴 조용한 구간
  높음: 6초 -> 3초
  중간: 6초 -> 4초
[4] Yu 외 표 1 평균 차이(높음-낮음 / 높음-중간)
  신뢰: 1.00 / 0.26
  만족: 1.35 / 0.38
  사용 의향: 1.20 / 0.40
[5] 가장 만족스러운 조건: 높음 26명, 중간 학생 12명, 설명 없는 인원 2명
[6] 중간을 고른 학생 12명은 40명의 30.0%, 학생 33명의 36.4%
```

확인하지 못하는 것: 사람이 그 시간을 어떻게 느끼는지, 어느 수준이 더 믿음을 주는지는 재지 않는다. 항목을 환불 화면에 옮긴 대응은 논문의 것이 아니라 이 장의 가정이다. 논문은 2분 시연 영상을 본 40명의 평가이고 정보의 양과 종류가 함께 바뀌었다.
