가상 데이터(진짜 d=0.4)에서 인원만 바꿔 표본 d와 95% 신뢰구간을 보고, 시드 1~200을 반복해 구간이 진짜 값을 포함하는 비율을 센다. 가이드 표의 한 줄이 조건, 대상, 이유, 근거, 강도를 모두 갖췄는지 검사하는 함수와 본문 가이드 표 일곱 줄(`GUIDE_ROWS`)도 있다. 강도는 직접 측정, 한 실험에서만, 한 실험에서만(논문 안 숫자 불일치 있음, 신뢰 낮음), 논문이 측정하지 않음 네 가지이다. `valid_guide_row`가 이 검사를 하는 함수 이름이다. 시드(seed)는 난수의 시작값이고, 가상 데이터는 정규분포(평균 4, SD 1)에서 뽑되 한 집단의 평균만 0.4 낮춰 만든다. 모든 숫자는 가상, 예시용이다.

- 실행: `python3 effect_reading.py`, 테스트: `python3 -m unittest -v`

손계산(가상, 예시용): 집단 A=[5,6,7], B=[3,4,5] -> 평균 6과 4, 분산 모두 1, d=2. SE=√(6/9+4/12)=1.0, 구간 2±1.96=[0.04, 3.96]. 3명씩은 정규 근사가 맞지 않는 규모이고 방법만 보이는 예이다.

기대 출력:
```
[1] 손계산 예: d=2.0, 구간 (0.04, 3.96)
  n=20: d=0.40, 구간 [-0.22, 1.03], 폭 1.25, 0 포함 True
  n=100: d=0.58, 구간 [0.29, 0.86], 폭 0.57, 0 포함 False
  n=400: d=0.46, 구간 [0.32, 0.60], 폭 0.28, 0 포함 False
[3] 반복: n=20 94.0%, n=100 92.5%, n=400 95.0% (표본 d 평균 0.41, 0.40, 0.41)
[4] n=100에서 표본 d가 0.58 이상인 시드: 200개 중 28개(14%)
[5] 가이드 표 7줄 검사: 통과 7줄, 대상 칸을 비운 줄은 걸러짐
```

확인하지 못하는 것: 정규 근사라 작은 표본에서는 거칠어질 수 있다(이 모의의 n=20은 94.0%로 크게 어긋나지 않았다). 가상 데이터에는 7점 척도의 상한과 하한이 없다. 집단 간 비교만 다룬다. 시간 지각은 시뮬레이션하지 않았다.
