# 6장 · 에이전트가 이 고객의 주문만 만지게 하려면 어디서 막아야 하나요?

가짜 모델은 메시지의 주문번호를 그대로 도구에 넘겨요. 같은 요청 20건(본인 10, 타인 6, 등록된 가족 대리 4)을 도구 권한 변형 6개에 넣고, 남의 주문 조회·환불이 나간 수와 정당한 요청이 막힌 수를 세요. 표준 라이브러리만 쓰고 난수가 없어요. 금액은 원(가상)이에요.

## 실행

```bash
python3 scoped_permissions.py
python3 -m unittest -v             # 시험 8개
```

## 기대 출력

| 변형 | 타인 조회 유출 | 타인 환불 건수 | 타인 환불 합계(원) | 막힌 본인 | 막힌 가족 | 사람 승인으로 넘어간 정당한 요청 |
|---|---|---|---|---|---|---|
| V1 번호만 맞으면 통과 | 3 | 3 | 241,000 | 0 | 0 | 0 |
| V2 모델이 넘긴 고객 ID | 3 | 3 | 241,000 | 0 | 0 | 0 |
| V3 환불 상한만 | 3 | 2 | 91,000 | 0 | 0 | 1 |
| V4 세션 고객 범위 | 0 | 0 | 0 | 0 | 4 | 0 |
| V5 세션 범위 + 상한 | 0 | 0 | 0 | 0 | 4 | 1 |
| V6 세션 범위 + 대리 등록표 + 상한 | 0 | 0 | 0 | 0 | 0 | 1 |

## 이 실습이 확인하지 못하는 것

실제 모델이 남의 주문 요청을 스스로 거절하는지, 프롬프트에 규칙을 적었을 때의 효과, 실제 로그인·세션 관리, 신원 확인 절차(대리 등록표는 가상), 조회·환불 외의 도구는 재지 않았어요.
