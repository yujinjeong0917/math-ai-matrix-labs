# 4장 실습: He 외(2025)의 보고값 다시 세기와 보정 점수의 구성 의존

He 외(2025)가 보고한 인원, 개입 횟수, 실패 분석 비율을 다시 계산해 보고값과 맞는지 본다. 가상 계획 묶음 두 개에서 "5점이면 믿고 5점 미만이면 믿지 않기" 점수가 계획 구성에 따라 어떻게 달라지는지 계산한다. 모든 숫자는 가상, 예시용이거나 논문 보고값이다.

- 실행: `python3 intervention_check.py`, 테스트: `python3 -m unittest -v`
- 출처: doi.org/10.1145/3706598.3713218 과 arXiv:2502.01390 (본문 열람 2026-11-16과 11-17, 서지 확인 2026-11-20).

기대 출력:
```
[1] 칸 인원 합 248명(모집 347명), 계획 개입 121명, 실행 개입 124명
[2] 계획을 한 번 이상 편집 104/121 = 86.0%, 행동 예측을 바꾼 상호작용 114/124 = 91.9%
[3] 계획 품질 5점 과제 717개 중 235개 오류: (717-235)/717 = 67.2% (논문 보고 66.7%)
[4] 오류 원인 비율 합 100.0%
[5] 가상 계획 묶음의 보정 점수(CT)
  고품질이 많은 묶음 [5, 5, 5, 5, 5, 4]: 고품질 5/6, 항상 믿기 0.833, 항상 믿지 않기 0.167, 완벽한 검토자 1.000
  결함이 많은 묶음 [2, 3, 4, 5, 2, 3]: 고품질 1/6, 항상 믿기 0.167, 항상 믿지 않기 0.833, 완벽한 검토자 1.000
```

확인하지 못하는 것: 가상 계획 묶음은 사람이 어떻게 믿는지를 재현하지 않는다. 점수가 어떻게 계산되는지만 보여 준다. 논문의 66.7%와 이 실습의 67.2%가 다른 이유는 알 수 없다.
