# 0장 실습: 읽은 연구의 범위 장부와 "같은 수락률, 다른 이야기" 세기

이 트랙이 근거로 읽은 네 편(Zhang 외 2025, Pareek 외 2026, Lee & See 2004, Parasuraman 외 2000)이 개월 단위 변화를 쟀는지 장부(`SOURCES`)로 적고, 가상 고객지원 팀의 로그 세 장(1개월 차, 3개월 차 A, 3개월 차 B)에서 수락률과 틀린 제안을 받아들인 수를 센다. 로그는 손으로 적은 고정 표이고, 신뢰나 습관을 모형으로 흉내 내지 않는다. 모든 로그 숫자는 가상, 예시용이다. 논문 값(Zhang 134편과 106편, Pareek 12명과 약 65분)은 논문에 적힌 값을 상수로 옮겼다. Zhang의 값은 arXiv v2 기준이고 2026-06 정오표가 값을 바꿨는지는 확인하지 못했다.

- 실행: `python3 evidence_ledger.py`, 테스트: `python3 -B -m unittest -v`

손계산(가상, 예시용): 1개월 차 로그는 제안 40건 가운데 수락 20+4=24건, 수락률 24/40=60%. AI 제안이 맞은 것은 20+8=28건이라 정답 비율 70%. 3개월 차 A와 B는 둘 다 수락이 32건이라 수락률 32/40=80%. 그런데 틀린 제안을 받아들인 수는 A가 2건, B가 8건이다.

본문의 스스로 점검 1번(가상): 제안 50건 중 수락 30건이면 30/50=60%.

기대 출력:
```
[2] Zhang: 패턴 분류는 106편/134편 = 79%
[3] 1개월 차: 제안 40건, 수락 24건 = 60%, AI 정답 28건 = 70%, 틀린 제안을 받아들인 수 4건
[3] 3개월 차 A: 제안 40건, 수락 32건 = 80%, AI 정답 32건 = 80%, 틀린 제안을 받아들인 수 2건
[3] 3개월 차 B: 제안 40건, 수락 32건 = 80%, AI 정답 28건 = 70%, 틀린 제안을 받아들인 수 8건
```
(`[1]`은 장부 네 줄이고 네 편 모두 개월 단위 변화를 쟀나 = False)

확인하지 못하는 것: 가상 로그는 이 장이 만든 것이라 실제 팀에서 이런 변화가 일어난다는 근거가 아니다. 수락은 행동이고 신뢰라는 태도를 잰 값이 아니다. 읽은 연구는 고객지원 현장을 다루지 않았다.
