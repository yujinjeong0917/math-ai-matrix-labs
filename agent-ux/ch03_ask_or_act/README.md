# 3장 실습: 가만히 있기, 묻기, 실행하기의 경계 계산하기

Horvitz(1999)의 기대 효용 틀에 가상 효용 여섯 개를 넣어 임계 확률 p*와, 묻기를 넣었을 때의 두 경계를 계산한다. 효용을 바꾸면 경계가 어떻게 움직이는지도 본다. 모든 숫자는 가상, 예시용이거나 논문 보고값이다.

- 실행: `python3 ask_or_act.py`, 테스트: `python3 -m unittest -v`
- 출처: doi.org/10.1145/302979.303030 (저자 공개 본문 열람 2026-11-20, 서지 확인 2026-11-20). 논문은 p*의 닫힌 식을 적지 않는다. 이 실습의 p*와 두 경계는 논문의 기대 효용 식에서 이 장이 유도한 값이다.

기대 출력:
```
[1] 가상 효용 u(행동,목표): AG=1.0, AnG=0.0, nAG=0.6, nAnG=1.0, DG=0.8, DnG=0.7
[2] p* = 1.00 / (1.00 + 0.40) = 0.714
[3] p=p*에서 실행의 기대 효용 0.714, 가만히의 기대 효용 0.714
[4] 묻기를 넣으면 경계가 둘: 가만히-묻기 0.600, 묻기-실행 0.778
[5] p별 선택
  p=0.50 -> 가만히
  p=0.65 -> 묻기
  p=0.75 -> 묻기
  p=0.80 -> 실행
  p=0.95 -> 실행
[6] 효용을 바꾸면 p*가 움직인다(가상)
  기준: p*=0.714
  틀린 환불 실행 u(A,nG) 0.0 -> 0.5: p*=0.556
  옳은 환불을 미룬 u(nA,G) 0.6 -> 0.3: p*=0.588
  옳은 환불을 미룬 u(nA,G) 0.6 -> 0.9: p*=0.909
```

확인하지 못하는 것: 효용 값은 모두 가상이다. 에이전트의 확신 점수가 보정된 확률이라는 보장은 없고 논문도 그것을 평가하지 않는다. 논문은 사용자 성과를 잰 결과를 보고하지 않는다.
