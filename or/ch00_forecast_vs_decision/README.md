# 0장. 예측 오차가 작은 쪽이 항상 더 좋은 결정을 줄까

세 지역(A·B·C)에 운동화 재고 60켤레를 나눠 보내는 가상 문제에서, 평균 절대 오차(MAE)가 더 작은 예측이 오히려 더 나쁜 배분을 낳는 장면을 재현합니다. 모든 숫자는 설명을 위해 일부러 만든 가상 값이며 실제 판매 자료가 아닙니다.

## 실행

```bash
cd or/ch00_forecast_vs_decision
python3 forecast_vs_decision.py
python3 -m unittest -v
```

## 기대 출력 (핵심)

```
P: MAE=2.67 배분={'A': 0, 'B': 22, 'C': 38} 이익=380,000원 후회=40,000원
Q: MAE=3.33 배분={'A': 0, 'B': 30, 'C': 30} 이익=420,000원 후회=0원
전수 탐색 최대 이익: 420,000
재고 60: 배분={'A': 0, 'B': 22, 'C': 38}
재고 90: 배분={'A': 22, 'B': 30, 'C': 38}
```

## 확인하지 못하는 것

- 실제 예측 모델의 오차 분포. 오차를 일부러 한 지역에 몰아 넣은 구성입니다.
- 예측이 틀릴 확률을 반영한 결정(13장), 예측과 인과효과의 연결(15장).
