# 1장 실습. 잠재결과, ATE·ATT·ITT, 선택 편향

웹 챕터: 인과추론 트랙 1장 「같은 사람의 쿠폰 있을 때와 없을 때를 왜 함께 볼 수 없을까요?」

가상(예시용) 쿠폰 장난감으로 세 가지를 확인합니다.

1. 여덟 명의 쿠폰 없을 때(Y0)와 있을 때(Y1) 값을 모두 아는 표에서 ATE(평균 처치효과), ATT(처치받은 사람의 평균 효과), 단순 비교, 선택 편향을 손으로 계산하고 `단순 비교 = ATT + 선택 편향`이 맞는지 봅니다.
2. 20,000명 시뮬레이션에서 열성도가 높은 사람이 쿠폰을 더 받아 가면 단순 비교가 ATE(2.48)의 두 배를 넘는지, 무작위로 나누면 그 편향이 사라지는지 봅니다.
3. 쿠폰을 무작위로 '배정'했지만 약 60%만 쓸 때 배정 기준 효과 ITT(배정된 대로 분석한 효과)가 사용 효과의 약 0.6배로 줄어드는지 봅니다.

## 실행

```bash
python3 potential_outcomes.py
python3 -m unittest -v
python3 -m pytest -q
```

## 기대 출력

```
손계산 표: ATE 2.5 / ATT 1.0 / ATC 4.0 / 단순 비교 14.0 = ATT 1.0 + 선택 편향 13.0
자기 선택: ATE 2.48 / ATT 2.08 / 단순 비교 6.42 / 선택 편향 4.34 / 받은 비율 0.503
무작위 배정: ATE 2.48 / ATT 2.48 / 단순 비교 2.49 / 선택 편향 0.01 / 받은 비율 0.500
배정 대비 ITT 1.48 / 실제 사용 비율 0.595 / ITT÷사용 비율 2.49
```

## 이 실습이 확인하지 못하는 것

- 현실에서는 Y0와 Y1을 한 사람에게서 동시에 볼 수 없습니다. 이 코드는 장난감이라서 둘 다 만들어 놓고, 방법이 진짜 값을 맞히는지 채점할 뿐입니다.
- 다른 사람의 쿠폰 사용이 내 결과에 영향을 주지 않는다는 가정(SUTVA, 개별 처치 안정성)은 코드에 그대로 넣어 두었고 검정하지 않습니다.
- 사용 효과를 ITT÷사용 비율로 읽으려면 배정이 무작위이고 배정받지 않은 사람은 쿠폰을 쓸 수 없다는 조건이 필요합니다. 이 장난감은 그 조건을 만족하게 만들었습니다.
