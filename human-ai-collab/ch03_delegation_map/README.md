# 3장 실습: 도우미 기능을 자동화 유형과 결정권으로 나누고 물어볼 질문 뽑기

가상 AI 도우미 기능 6개(과거 티켓 찾기, 티켓 요약, 답변 초안 제안, 환불 승인 추천, 답변 자동 발송, 고객에게 먼저 추가 질문 보내기)를 Parasuraman 외(2000)의 네 유형(정보 획득, 분석, 결정, 행동)과 Zhang 외(2025)의 결정권 관련 세 축(누가 결정권을 쥐나, 분배가 상황에 따라 바뀌나, 큰 방향인가 세부인가)으로 적은 표(`FEATURES`)에서, 기능마다 팀이 먼저 물어볼 질문을 꺼낸다. 질문은 점검용이고 어느 자동화 수준이 옳은지 정하는 기준이 아니다(Parasuraman 외는 모형이 처방하지 않는다고 밝힌다). 수준 번호나 개수 기준은 쓰지 않았다. 기능 표의 값은 가상, 예시용이다. Zhang 외의 패턴 분포(수동 18, 반응 34, 반능동 12, 선제 9, 협력 33, 합 106편)와 134편, CHI 108편은 논문에 적힌 값이며 arXiv v2 기준이고 2026-06 정오표가 값을 바꿨는지는 확인하지 못했다.

- 실행: `python3 delegation_map.py`, 테스트: `python3 -B -m unittest -v`

손계산: 반응 34/106=0.3208이라 약 32%, 협력 33/106=0.3113이라 약 31%, 수동 18/106=17%, 반능동 12/106=11%, 선제 9/106=8%. CHI 108/134=0.806이라 약 81%. 가상 기능 6개 가운데 수락이나 수정 기록이 남는 것은 답변 초안 제안과 환불 승인 추천 2개다. 답변 자동 발송은 사람 확인이 없고 되돌릴 수 없으며 결정권이 AI에 있고 수락 기록이 없어서 질문 3개가 나온다.

본문의 스스로 점검 2번(가상): 기능 8개 중 수락 기록이 남는 것이 3개면 3/8=37.5%. Zhang 외의 검색은 2024년 8월까지의 논문을 대상으로 했다.

기대 출력:
```
[1] Zhang 외 패턴 분포(106편): 수동 18편(17%), 반응 34편(32%), 반능동 12편(11%), 선제 9편(8%), 협력 33편(31%)
[2] 말뭉치 중 CHI 108/134 = 81%
[3] 가상 기능 6개 중 수락 기록이 남는 기능 2개
  비슷한 과거 티켓 찾기: 획득, 결정권 상담원, 질문 1개
  티켓 자동 요약: 분석, 결정권 상담원, 질문 1개
  답변 초안 제안: 결정, 결정권 공동, 질문 1개
  환불 승인 추천: 결정, 결정권 공동, 질문 2개
  답변 자동 발송: 행동, 결정권 AI, 질문 3개
  고객에게 먼저 추가 질문 보내기: 행동, 결정권 AI, 질문 3개
```

확인하지 못하는 것: 기능을 네 유형 중 어디에 넣을지는 이 장이 정한 분류이고 Parasuraman 외가 이 기능들을 분류한 것이 아니다. 질문 개수는 어떤 기능이 더 위험한지 점수로 쓸 수 없다. Zhang 외는 문헌 분류이고 패턴 편수는 어떤 패턴이 성과를 높이는지를 말하지 않는다. 고객지원 현장의 자동화 효과는 다루지 않는다.
