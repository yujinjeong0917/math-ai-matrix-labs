# 3장 실습: 화면 이동 점수와 CLS

web.dev 문서의 계산 예(영향 비율 x 거리 비율)를 확인하고, 가상 결제 화면의 이동 기록으로 점수, 세션 창(간격 1초 미만, 최대 5초), 입력 직후 이동 제외를 거쳐 CLS를 구한다. 모든 이동 기록은 가상, 예시용이다.

- 실행: `python3 cls_shifts.py`, 테스트: `python3 -m unittest -v` (표준 라이브러리만, 난수 없음)
- 기준값 출처: web.dev 문서(2026-11-20 확인, 정리해서 옮김, 문장 인용 아님). 4장의 논문 값은 저자 공개본 PDF(2026-11-20 확인).

손계산: 문서의 예 0.75 x 0.25 = 0.1875, 0.5 x 0.14 = 0.07, 0.60 x 0.30 = 0.18. 이동 점수는 영향 비율 min(1, 높이 + 거리)에 거리를 곱한다: 0.60 x 0.10 = 0.06, 0.60 x 0.15 = 0.09, 0.45 x 0.05 = 0.0225. 1.2초, 1.7초, 2.4초는 간격이 1초 미만이라 한 창이고 합 0.1725, 6.0초는 새 창이다. 8.0초 이동은 탭 직후라 뺀다. CLS = 0.1725(개선 필요).

기대 출력:
```
[문서의 예] 0.75 x 0.25 = 0.1875
[문서의 예] 0.5 x 0.14 = 0.07
[문서의 예] 0.6 x 0.3 = 0.18
[이동] 1.2초: 높이 0.5, 거리 0.1, 영향 0.6 -> 점수 0.06
[이동] 1.7초: 높이 0.45, 거리 0.15, 영향 0.6 -> 점수 0.09
[이동] 2.4초: 높이 0.4, 거리 0.05, 영향 0.45 -> 점수 0.0225
[이동] 6.0초: 높이 0.3, 거리 0.02, 영향 0.32 -> 점수 0.0064
[이동] 8.0초: 높이 0.5, 거리 0.2, 영향 0.7 -> 점수 0.14 (입력 직후라 뺌)
[창 1] 1.2초부터 2.4초, 이동 3번, 합 0.1725
[창 2] 6.0초부터 6.0초, 이동 1번, 합 0.0064
[결제 방문 CLS] 0.1725(개선 필요), 모든 이동의 합(입력 직후 포함) 0.3189
[간격] 1.2초와 1.7초 0.5초, 1.7초와 2.4초 0.7초, 2.4초와 6.0초 3.6초
[꾸준한 이동] 이동 8번, 합 0.16, 창 2개([7, 1]번씩), CLS 0.14
[점검 1] 0.5 x 0.2 = 0.1(좋음)
[점검 2] 이동 1.0, 1.5, 2.0초: CLS 0.12(개선 필요), 세 번째가 3.5초이면 CLS 0.07(좋음), 창 [2, 1]번씩
[같은 점수] 아래쪽 안내 문구가 밀림 0.1224, 결제 버튼이 밀림 0.1224
```

확인하지 못하는 것: 영향 비율은 화면 폭 전체를 쓰는 요소가 세로로만 움직이는 단순화다(실제 화면은 모양과 방향이 다르다). 5초 경계의 정확한 자르는 방식은 확인하지 못했다. 같은 점수라도 어느 요소가 밀렸는지는 점수에 들어가지 않는다. 사용자가 느낀 불편, 잘못 누른 횟수는 계산하지 않는다.
