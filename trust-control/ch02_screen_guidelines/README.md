# 2장 실습: 답변 도우미 화면을 지침으로 점검한다 (가상 화면)

가상 쇼핑몰의 AI 답변 도우미 화면 3개(답변만, 근거 문장 추가, 정확도 안내와 오류 신고와 상담원 연결까지)를 지침 6개(1, 2, 8, 9, 10, 11번)로 점검해 적용, 위반, 해당 없음을 센다. 화면과 평정은 가상, 예시용이다. 지침 번호는 Amershi 외(2019)를 따르고 문구는 이 장의 말로 옮겼다. 논문이 정리 후 보고한 평정 개수(적용 313, 위반 277, 중립 89, 해당 없음 106)의 합이 785인지와 비율도 계산한다.

- 실행: `python3 guideline_audit.py`, 테스트: `python3 -m unittest -v`

손계산: 화면 2는 지침 1, 8, 11이 적용이라 적용 3, 나머지 2, 9, 10이 위반이라 위반 3. 논문 개수는 313+277=590, 590+89=679, 679+106=785. 적용 비율 313/785=39.9%.

기대 출력:
```
[1] 화면 1 (답변만): 적용 1, 위반 5, 해당 없음 0 (위반: [1, 2, 9, 10, 11])
[1] 화면 2 (답변 + 근거 문장): 적용 3, 위반 3, 해당 없음 0 (위반: [2, 9, 10])
[1] 화면 3 (근거 + 정확도 안내 + 오류 신고 + 상담원 연결): 적용 6, 위반 0, 해당 없음 0 (위반: [])
[2] 논문 보고 개수 합 313 + 277 + 89 + 106 = 785
[3] 비율 적용 39.9%, 위반 35.3%, 중립 11.3%, 해당 없음 13.5%
[4] 이 점검은 요소가 있는지만 센다. 신뢰나 성과가 달라지는지는 재지 않았다.
```

확인하지 못하는 것: 점검 결과가 좋다고 사용자 신뢰가 보정된다는 근거는 없다. 논문은 지침이 관찰되는지와 이해되는지를 확인했고 지침을 따른 설계가 사용자 결과를 바꾸는지는 재지 않았다. 논문의 제품 20개에는 대화형 대규모 언어 모델 제품이 없다.
