# 4장 실습: 펼쳐 보기 기록에서 틀린 제안과 맞은 제안의 펼침 비율 세기

가상 고객지원 팀의 AI 제안 화면에는 근거를 접어 둔 "펼치기" 버튼이 있다. 1개월 차와 3개월 차에 제안 40건씩의 기록(AI가 틀렸나 맞았나 x 펼쳐 봤나)을 손으로 적은 고정 표(`LOG`)로 두고, 펼침 비율과 선택도(틀린 제안의 펼침 비율에서 맞은 제안의 펼침 비율을 뺀 퍼센트포인트)를 센다. 모든 로그 숫자는 가상, 예시용이다. 사람의 점검 습관을 모형으로 만들지 않았다. 선택도는 이 장이 정한 값이다. Pareek 외(2026)의 값(12명, 토글을 원한 8명, 시간이 지나면 정보가 덜 필요해질 것이라고 말한 2명, 변형 5종, 과제 2종)은 논문에 적힌 값을 `PAREEK` 상수로 옮겼고, 그 연구는 질적 관찰이라 이 코드는 그 값에 구간이나 검정 같은 통계 계산을 하지 않는다.

- 실행: `python3 disclosure_log.py`, 테스트: `python3 -B -m unittest -v`

손계산(가상, 예시용): 1개월 차에 틀린 제안은 12건이고 그중 펼친 것이 9건이라 9/12=75.0%, 맞은 제안은 28건이고 펼친 것이 15건이라 15/28=53.6%, 선택도 75.0-53.6=+21.4p, 전체 펼침 24/40=60%. 3개월 차는 틀린 제안 4/12=33.3%, 맞은 제안 8/28=28.6%, 선택도 +4.8p, 전체 12/40=30%.

소수로 쓰면 1개월 차 선택도는 0.750-0.536=0.214. 본문의 스스로 점검 1번(가상): 6/10-20/40=0.60-0.50=+10p. 본문이 인용하는 논문 값: Pareek 외 참가자 평균 나이 27.4세, Zhang 외 말뭉치 134편(arXiv v2 기준, 정오표 반영 여부 미확인).

기대 출력:
```
[1개월 차] 전체 펼침 60%, 틀린 제안 9/12 = 75.0%, 맞은 제안 15/28 = 53.6%, 선택도 +21.4p
[3개월 차] 전체 펼침 30%, 틀린 제안 4/12 = 33.3%, 맞은 제안 8/28 = 28.6%, 선택도 +4.8p
```

확인하지 못하는 것: 펼침 비율이 줄어든 이유가 숙련인지 점검 소홀인지는 이 로그로 가를 수 없다. 틀린 제안이 12건뿐이라 비율의 흔들림이 크고 구간을 계산하지 않았다. 펼쳐 봤다는 것이 읽었다는 뜻은 아니다. 로그에는 상담원이 근거를 이해했는지 기록이 없다. Pareek 외의 참가자 발언은 이 로그와 비교할 수 있는 값이 아니다.
