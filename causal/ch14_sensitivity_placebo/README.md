# 14장. 민감도, 위약검정, 외적타당도

웹 챕터: `tracks/causal/14-sensitivity-placebo-external-validity.html`

세 가지를 한 파일에서 재현합니다.
1. 관측되지 않은 충성도 U가 있는 관측 데이터에서 편향 공식(편향 = 영향력 x 평균 차이)이 맞는지 확인하고 민감도 표를 만듭니다.
2. 20개 지역 패널에서 공간 위약검정과 시간 위약검정이 각각 무엇을 잡고 무엇을 놓치는지 비교합니다.
3. A지역 실험 결과를 신규 고객 비중이 다른 B지역에 옮길 때 다시 가중하면 얼마나 가까워지는지, 숨은 요인이 있으면 어떻게 어긋나는지 봅니다.

```bash
python3 robustness.py
python3 -m unittest -q
```

기대 출력(요약):

```
진짜 효과 1500원 / 단순 차이 5417원 / h로 층화 4588원
숨은 U의 평균 차이 delta=0.776, 편향 공식 4000*delta=3104원, 숨은 요인 보정 추정 1484원
평행추세 세계: DiD 9.51, 공간 위약 순위 1/20, 시간 위약 0.21, 시간 위약 순위 16/20
처치 지역만 가파른 세계: DiD 8.51, 공간 위약 순위 1/20, 시간 위약 4.71, 시간 위약 순위 1/20
A 실험 ATE 2168원 / 그대로 옮김 2168원 / 다시 가중 1192원 / B 진짜 1080원
```

확인하지 못하는 것: U를 가상 세계에서 알고 있어서 편향 공식 검증이 가능하지만, 실제 분석에서는 delta와 영향력을 알 수 없고 가정으로만 둡니다. 이 코드는 E-값, 로버스트니스 값(robustness value) 같은 확률비 기반 지표는 구현하지 않습니다. 선형 결과와 단일 숨은 변수만 다룹니다.
