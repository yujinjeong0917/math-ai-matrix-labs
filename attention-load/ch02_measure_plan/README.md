# 2장 실습: 문항 일관성, 자기보고와 행동 기록의 순위 관계, 측정 계획 경고

가상 응답 5명 x 문항 3개(1~7점)로 크론바흐 알파를 손과 코드로 맞춰 보고, 같은 총점이 서로 다른 두 가상 완료 시간 자료와 맺는 순위 상관(스피어만)을 계산한다. 측정 계획 두 가지에는 "모두 자기보고", "문항 겹침 후보" 경고를 붙인다.

- 입력: `virtual_data.json` (모두 가상, 예시용. 실제 사람의 응답이 아니다)
- 실행: `python3 measure_plan.py`, 테스트: `python3 -m unittest -v`

기대 출력:
```
[0] 항목별 분산 [2.5, 0.7, 3.3], 총점 평균 11.4, 총점 편차 제곱합 69.2
[1] 총점 [14, 8, 17, 7, 11], 항목 분산 합 6.5, 총점 분산 17.3, 알파 0.936 (응답 5명)
[1b] 1 - 항목 분산 합 / 총점 분산 = 0.624
[2] 총점과 완료 시간의 순위 상관: 시간 자료 A 1.000, 시간 자료 B 0.000
[3] 계획 A 경고 2개: 모두 자기보고; 문항 겹침 후보(주의 분산 문항, 어려움 문항: 신경)
[3] 계획 B 경고 0개: 없음
```

확인하지 못하는 것: 이 숫자는 계산법을 보이려고 만든 것이라 실제 화면에서 알파나 순위 상관이 얼마가 나오는지 말하지 않는다. 5명으로 구한 알파는 매우 불안정하다. 순위 상관 1.000과 0.000은 두 가상 자료를 일부러 다르게 만든 결과다. 문항 겹침 경고는 계획 작성자가 적은 낱말 목록만 비교하므로 문항 뜻이 비슷한지 판단하지 못한다. 주의나 머리 부담이 어떤 점수로 재어지는지는 이 코드가 정하지 않는다.
