# 고객지원팀 작업 지침

이 폴더는 고객지원팀이 AI 도우미와 함께 쓰는 작업 폴더예요.

## 늘 지킬 것
- 답은 해요체로 써요.
- 날짜는 2026-10-12처럼, 시각은 14:30처럼 써요.
- 고객 이름, 전화번호, 주소는 결과물에 옮기지 않아요. 문의 번호(#0001)로 가리켜요.
- 확인하지 못한 내용은 [확인 필요]라고 적어요.

## 폴더
- `exports/`: 고객 문의 내보내기 CSV. 읽기만 하고 고치지 않아요.
- `reports/`: 완성한 주간 보고서. 파일 이름은 2026-W41.md 모양이에요.

## 자주 하는 일
- 주간 보고서, 환불 답장, 회의록, 업데이트 안내, 화면 문구 점검, 설문 요약은 각각 스킬로 있어요. 절차는 스킬 본문을 따라요.
