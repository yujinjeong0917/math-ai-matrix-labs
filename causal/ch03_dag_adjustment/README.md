웹 챕터: 인과추론 트랙 3장 「회귀식에 무엇을 넣고 무엇을 빼야 할까요?」

가상(예시용) 쿠폰 장난감에서 쿠폰이 월 구매액에 주는 전체 효과는 2.0입니다(직접 0.5 + 장바구니 크기를 거친 몫 1.5×1.0). 세 변수를 회귀식에 넣고 빼면서 쿠폰 계수가 2.0을 맞히는지 봅니다.

- 손계산 표(1,000명)와 회귀 실험(20,000명)은 서로 다른 장난감입니다. 둘 다 진짜 효과는 2.0이고 단순 차이는 각각 11.43, 5.00으로 다릅니다.
- Z 충성도: 쿠폰도 더 받고 구매도 더 많이 하는 교란변수
- M 장바구니 크기: 쿠폰의 결과이면서 구매액의 원인인 매개변수
- C 후기 점수: 쿠폰과 구매액의 결과인 충돌변수

최소제곱은 정규방정식을 가우스 소거법으로 직접 풉니다. 손계산 표(가상 1,000명)에서 층별 비교와 층 가중 평균도 대조합니다.

## 실행

```bash
python3 dag_adjustment.py
python3 -m unittest -v
python3 -m pytest -q
```

## 기대 출력

```
손계산: 받은 사람 평균 29.43 / 못 받은 사람 평균 18.00 / 단순 차이 11.43 / 층 안 차이 {'높음': 2.0, '낮음': 2.0} / 층 가중 평균 2.00
진짜 전체 효과 2.0 (직접 0.5 + 매개 1.5*1.0)
쿠폰을 충성도 높은 사람이 더 받는 관찰 데이터:
  아무것도 안 넣음          T 계수 5.00
  충성도 Z              T 계수 1.99
  Z + 장바구니 M         T 계수 0.52
  Z + 후기 점수 C        T 계수 -0.51
  전부 다(Z, M, C)      T 계수 -0.72
쿠폰을 동전으로 배정한 데이터:
  아무것도 안 넣음          T 계수 1.96
  충성도 Z              T 계수 1.99
  Z + 장바구니 M         T 계수 0.44
  Z + 후기 점수 C        T 계수 -0.51
  전부 다(Z, M, C)      T 계수 -0.72
시드를 바꿔 12번 만든 평균(표준편차):
  관찰       아무것도 안 넣음          4.99 (0.06)
  관찰       Z + 장바구니 M         0.48 (0.04)
  동전 배정    아무것도 안 넣음          1.99 (0.06)
  동전 배정    Z + 장바구니 M         0.50 (0.03)
```

## 이 실습이 확인하지 못하는 것

- 화살표 구조는 코드를 쓰는 사람이 정해 준 것입니다. 실제 데이터에서는 어떤 화살표가 있는지 데이터만으로 확정할 수 없고, 도메인 지식과 시간 순서로 정해야 합니다.
- 모든 관계를 직선(선형)으로 만들었습니다. 비선형 관계나 상호작용이 있으면 계수가 단순하게 읽히지 않습니다.
- 충성도 Z를 오차 없이 쟀다고 가정했습니다. 실제로는 Z를 대충 재면 교란이 일부 남습니다.
- 숨은 교란변수(관측하지 못한 원인)는 넣지 않았습니다. 이 경우에는 어떤 변수를 넣어도 해결되지 않고, 민감도 분석이나 다른 식별 전략이 필요합니다.

- 한 번 만든 20,000명의 계수는 0.05 안팎으로 흔들립니다(예: 동전 배정에서 Z + M 0.44, 아무것도 안 넣음 1.96). 시드를 바꿔 평균을 내면 직접 몫 0.5와 전체 효과 2.0 근처로 모입니다.
