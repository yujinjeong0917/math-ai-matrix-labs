# 7장 실습. 시차 도입 이중차분과 이벤트스터디

웹 챕터: https://math-ai-matrix-pi.vercel.app/tracks/causal/07-staggered-did-event-study.html

가상 온라인 마켓에서 지역 A는 3주차, 지역 B는 7주차에 쿠폰을 시작하고 지역 C는 끝까지 쿠폰이 없습니다(지역당 가게 20곳, 10주). 쿠폰 효과는 시작 후 주가 지날수록 커지도록 정해 두었어요(첫 주 +3, 둘째 주 +6, ... 천 원 단위 가상). 이 데이터에서
1. 가게·주 고정효과를 넣은 이원고정효과(TWFE) 계수가 진짜 평균 효과와 얼마나 다른지, 처치 칸마다 어떤 가중치를 받는지 계산하고
2. 아직 쿠폰이 없는 지역만 대조로 쓰는 그룹-시점 비교(Callaway·Sant'Anna 방식을 단순화)로 이벤트스터디를 그려 진짜 값과 비교합니다.

## 실행

```bash
cd causal/ch07_staggered_did_event_study
python3 staggered.py         # 본문 숫자를 모두 출력
python3 -m unittest -v       # 출력값을 고정한 검사 (pytest도 가능)
```

표준 라이브러리만 씁니다. 난수는 `random.Random(seed).random()`만 쓰고 정규분포는 직접 만듭니다.

## 기대 출력 (일부)

```
진짜 평균 효과(처치 칸 단순 평균) 11.50
TWFE 계수 5.88 (가중치로 계산한 진짜 효과 평균 6.00, 차이 0.12는 잡음)
가중치 합: A 0.375 (3~6주차 +0.500, 7~10주차 -0.125), B 0.625
음수 가중치 칸 80/240 (B 도입 뒤의 A 칸 전부)
깨끗한 비교의 e=+0 ... e=+7: +2.93 ... +23.77 (진짜 +3 ... +24)
대조 지역 C 없이 A, B만: TWFE 계수 -0.66 (가중치로 계산한 값 -0.50)
효과가 +8로 일정할 때: TWFE 계수 7.88 (잡음 0이면 8.00)
```

## 이 실습이 확인하지 못하는 것

- 평행추세는 이 장난감에서 참이 되도록 만들었습니다. 실제 데이터에서는 사전 기간 가짜 효과가 0 근처라는 것만 확인할 수 있고 증명은 안 돼요.
- 그룹-시점 비교는 대조 지역이 C 하나뿐이고 공변량이 없는 가장 단순한 판입니다. 실제 라이브러리의 이중강건 추정, 표준오차, 동시 신뢰구간은 구현하지 않았습니다.
- TWFE 이벤트스터디(상대 시점 더미 회귀)는 구현하지 않았습니다. 표준 TWFE 계수 하나의 가중치만 계산했어요.
- 한 번의 시드(11)로 만든 하나의 패널입니다. 같은 구조에서 숫자는 조금 달라질 수 있지만 가중치의 부호는 설계(누가 언제 도입했는가)가 정합니다.
