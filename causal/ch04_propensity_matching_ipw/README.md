# 4장 실습. 성향점수·매칭·IPW

웹 챕터: https://math-ai-matrix-pi.vercel.app/tracks/causal/04-propensity-matching-ipw.html

가상 온라인 마켓에서 쿠폰이 구매 활동이 많은 고객에게 더 자주 갔을 때, 단순 비교·성향점수 IPW(역확률가중)·1:1 매칭이 진짜 효과 +8.0(천 원, 가상)을 얼마나 맞히는지 잽니다. 진짜 효과는 데이터를 만들 때 정해 두었으니 정답과 직접 비교할 수 있어요. 쿠폰이 상위 고객에게 거의 몰려 겹침이 무너진 장면도 같이 돌립니다.

## 실행

```bash
cd causal/ch04_propensity_matching_ipw
python3 propensity.py            # 본문 숫자를 모두 출력
python3 -m unittest -v           # 출력값을 고정한 검사 (pytest도 가능)
```

표준 라이브러리만 씁니다. 난수는 `random.Random(seed).random()`만 쓰고 정규분포는 직접 만들어, 파이썬 버전이 달라도 같은 값이 나옵니다.

## 기대 출력 (일부)

```
단순 비교: 쿠폰 63.6, 비쿠폰 36.4, 차이 27.2
층별 비교 후 평균(ATE): 8.0
IPW: 처치 54.0, 비처치 46.0, 차이 8.0
...
IPW(ATE) 7.97 / 1:1 매칭(ATT) 7.93 / 단순 비교 15.67      (겹침 충분)
IPW(ATE) 19.52, 진짜 ATE 8.11, 최대 가중치 232.8             (겹침 부족)
```

## 이 실습이 확인하지 못하는 것

- 성향점수 모형이 맞는 장난감입니다(로지스틱이 진짜 배정 규칙). 모형이 틀린 경우는 이 트랙의 다음 장(AIPW)에서 다룹니다.
- 관측한 변수(x)만 쓰고 있어요. 관측하지 못한 교란은 성향점수로 풀리지 않습니다.
- 매칭은 처치군 평균효과(ATT), IPW는 전체 평균효과(ATE)를 추정해서 두 숫자를 직접 비교하면 대상이 다릅니다.
- 표준오차와 신뢰구간은 계산하지 않았습니다. 반복 200번의 표준편차로 흔들림만 봅니다.
