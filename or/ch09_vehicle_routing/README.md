정지점 8곳(수요 합 25박스), 차량 용량 10박스인 가상 도시에서 경로 묶기(VRP)를 전수 탐색으로 풉니다. 단순 순서 묶기, 가까운 곳 먼저 규칙과 정확한 최적값을 비교하고, 시간창과 교통 혼잡을 넣어 답이 깨지는 모습을 봅니다. 거리는 맨해튼 거리(분과 같은 단위), 정지점마다 내려놓는 시간은 5분입니다. 좌표·수요·시간창은 모두 학습용 가상값입니다.

```bash
python3 routing.py
python3 -m unittest -v
```

## 기대 출력(요약)

- 단순 순서 묶기 78, 가까운 곳 먼저 82, 전수 탐색(최대 3대) 76, 최대 2대는 해 없음
- 시간창 느슨 3대 78, 빡빡 3대 해 없음, 빡빡 4대 88
- 용량 13박스 차량 최대 2대 62, 용량 10박스에서 평가하는 묶음 85개·방문 순서 412가지
- 속도 0.7배 + 느슨한 시간창은 3대·4대 모두 해 없음

## 이 실습이 확인하지 못하는 것

- 정지점이 8곳일 때만 전수 탐색이 됩니다. 수십 곳 이상은 OR-Tools 같은 전용 솔버나 휴리스틱이 필요하고, 그때 얻은 해가 최적이라는 보장은 없습니다.
- 실제 도로망·교통 예측·재배송·기사 휴식 규정은 들어 있지 않습니다. 속도 0.7배는 모든 구간이 똑같이 느려지는 가장 단순한 가정입니다.
- 시간창은 "출발 후 몇 분까지 도착"만 다루고, 이른 도착 시 대기는 허용합니다. 고객 불만·위약금 같은 비용은 모형 밖입니다.
