# 5장. 정수계획: 상담원 1.6명을 배치하라는 해, 그대로 써도 될까

무엇을 재나: 가상의 상담 인력 배치(정규·시간제)에서 LP 완화 해, 반올림 해, 분기한정 해, 전수 탐색 해를 같은 문제에서 대조한다. 계수는 모두 예시용 가상값이다.

실행(이 폴더 안에서):

```bash
python3 -m unittest -v
python3 integer_programming.py
```

기대 출력(요약):

- LP 완화 최적 (8/5, 11/5), 처리량 84/5 = 16.8
- 반올림 (2, 2)는 인건비 14로 한도 13 초과. 가능한 바닥/천장 조합 중 최선은 (1, 2)의 13
- 전수 탐색과 분기한정 모두 (3, 0), 처리량 15. 가능한 정수점 10개, 분기한정 노드 13개
- 인건비 한도 10~16의 정수 최적: 13, 14, 15, 15, 18, 19, 20

확인하지 못하는 것: 실제 상담팀의 생산성·비용, 교대와 숙련도, 외부 솔버(HiGHS, OR-Tools)와의 결과 비교. 이 코드의 LP는 꼭짓점 열거라 변수가 많아지면 쓸 수 없다. 변수 4개 이하의 학습용이다.
