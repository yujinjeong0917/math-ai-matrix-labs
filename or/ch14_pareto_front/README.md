세 지역(A·B·C)에 배송 인력을 0~6명 배치하는 343개 경우를 모두 나열해 총비용과 가장 느린 지역의 배송일로 파레토 전선(15개)을 만들고, 가중합이 뽑는 점(8개)과 못 뽑는 점(7개), ε-제약이 찾는 점을 비교한다. 모든 값은 학습용 가상값이다.

## 실행

```bash
cd or/ch14_pareto_front
python3 pareto_front.py
python3 -m unittest -v
```

## 기대 출력 (일부)

```
전체 배분 수: 343
파레토 전선 점 수: 15
어떤 가중치로도 못 뽑는 전선 점: [(8.0, 2.94), (13.0, 2.058), (16.0, 2.0), (19.0, 1.4406), (22.0, 1.4), (25.0, 1.00842), (28.0, 0.98)]
배송일 2.0 이하 -> 비용 최소 16.0 배분 (0, 2, 4) 가장 느린 2.000일
```

## 확인하지 못하는 것

- 공정성을 다른 방식(격차, 비율, 주문 수 가중 평균)으로 정의했을 때의 전선.
- 가중치 구간은 0~5를 0.001씩 훑은 값이라 경계 근처는 0.001 단위로만 안다.
- 연속 변수 문제에서 가중합이 전선 전체를 뽑는 조건의 증명은 이 실습에 없다.
