# 8장. 도구를 무엇으로 고를까 (`ch08_choosing`)

웹 챕터: `math-ai-matrix/tracks/tools/08-choosing.html`

관통 프로젝트(가상의 작은 팀이 만드는 "주간 고객 문의 요약 보고서")의 마지막 장이다. 1~5장에서 붙인 도구를 놓고 비용, 데이터 처리 약관, 프롬프트 주입 세 갈래로 고르는 기준을 세우고, 질문 10개짜리 점검표로 후보 구성 4개를 판정한다. 네트워크·API 키 없이 재현한다.

1. 앞 장 `results/*.json`에서 숫자를 옮겨(`data/upstream_2026-10-10.json`) 한 달 비용 표를 만든다. 한 달 = 한 주 × 52 / 12. 행마다 센 것과 단위가 달라 더하거나 줄 세우지 않는다. API 사용료만 세고 좌석·구독료는 넣지 않는다. 6장 행은 달러가 아니라 끝까지 옳은 주의 비율과 승인 수, 7장 행은 "매주 한 편" 가정의 생성 사용료 범위다.
2. 주요 제공사의 데이터 처리 약관(학습 기본값, 보관 기간, 지역, 개인용과 기업용 차이)을 공식 문서에서 확인해 `data/policies_2026-10-10.json`에 출처 URL, 확인일, 원문 문장과 함께 적는다.
3. 5장 프롬프트 주입 장난감을 이어받아, 숨은 지시 4개와 지시처럼 보이는 평범한 문의 1개가 든 가상 문의 20건에서 고리 6가지(순진한 고리, 낱말 거르개, 자료로만 읽기, 코드 속 확인 문, 사람이 보고서 읽기)를 비교한다.
4. 팀 조건과 질문 10개로 후보 구성 4개를 통과 / 막힘 / 확인 필요 / 해당 없음으로 판정한다. 점수나 순위는 내지 않는다.

## 실행
```bash
uv run python tools/ch08_choosing/experiments.py   # results/ch08.json 갱신
uv run pytest -q tools/ch08_choosing
python tools/ch08_choosing/tools_ch08_data.py      # 앞 장 스냅숏과 가상 문의 다시 만들기
```
표준 라이브러리만 쓴다. 실제 모델·Notion·Figma·메일을 부르지 않는다.

## 한계
- 모델을 부르지 않는다. "글 속 지시를 따른다"는 정규식 4개로 흉내 냈고, 자료로만 읽는 고리가 새는 종류(관리자 지시처럼 꾸민 글, 공손한 부탁 글)는 가정이다. 실제 모델이 무엇을 따를지는 이 모형으로 알 수 없다.
- N × p × q 계산의 p, q는 예시 값이고 두 단계가 독립이라고 가정했다. 95%는 Simon Willison 글이 인용한 업체 주장이지 측정한 막는 비율이 아니다.
- 비용 표의 4장 행은 지시문 토큰만 2달러/100만 토큰으로 바꾼 값이라 다른 행과 같은 일을 센 것이 아니다. 5장 행은 달러가 아니라 호출 수다.
- 약관은 2026-10-10에 읽은 문서 기준이다. 글자로 확인하지 못한 항목은 사실 파일 note에 [확인 필요]로 남겼다.
