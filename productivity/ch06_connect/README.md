# 6장. 세 도구를 무엇으로 잇나 (`ch06_connect`)

웹 챕터: `math-ai-matrix/tracks/productivity/06-connect.html`

Figma·Notion·Google Sheets를 띄우지 않고, 관통 프로젝트(동네 스터디룸 예약)의 정보 항목 12개가 놓인 위치 34곳과
1주 변경 이벤트 12개를 파이썬 모형에 넣어, 도구 사이를 잇는 규칙이 무엇을 줄이고 무엇을 새로 만드는지 센다.

1. 등록부를 방향 그래프로 본다(노드 = 위치, 간선 = 원본 -> 참조). 원본 하나, 한 곳에서만 받기, 고리 없음, 모두 닿음을 검사한다.
2. 같은 이벤트를 다섯 방식(규칙 없음 / 등록부만 / 등록부 + 권한 + 버전 / + 자동화(함정 그대로) / + 자동화(대비))으로 넣고
   불일치, 체크리스트 미충족, checks FALSE, 추적 불가 변경, 쓴 시간을 센다. 시드 1000개, q = 0.7~0.95.
3. 공식 문서에 적힌 자동화 동작(스크립트 편집은 트리거를 안 부름, 자동화가 만든 페이지는 다음 자동화를 안 부름,
   설치형 트리거는 만든 사람 계정, 속성 이름이 바뀌면 이름으로 찾는 코드가 멈춤, 웹훅 순서가 바뀜)을 이벤트로 넣는다.
4. 양방향 동기화(원본이 둘)와 웹훅 도착 순서를 따로 재고, 깨진 자동화를 알아채기까지 걸린 날을 센다.

## 실행
```bash
OMP_NUM_THREADS=2 uv run python productivity/ch06_connect/experiments.py   # results/ch06.json, data/*.json, checks/ch06.csv 갱신
uv run pytest -q productivity/ch06_connect
```
표준 라이브러리와 NumPy만 쓴다. 도달 집합(한 위치가 바뀌면 어디까지 퍼지나)은 BFS, NumPy 불리언 행렬 거듭제곱,
sqlite3 재귀 CTE 세 방식으로 구현해 무작위 등록부 500개에서 대조한다. PyTorch로 옮길 계산이 없어 쓰지 않았다.
