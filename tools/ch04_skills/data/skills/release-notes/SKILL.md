# 업데이트 안내 글

## 순서
1. 바뀐 점을 고객이 체감하는 것(새 기능, 고친 오류)과 체감하지 않는 것(내부 정리)으로 나눠요. 체감하지 않는 것은 쓰지 않아요.
2. 새 기능은 "이제 ~할 수 있어요"로, 고친 오류는 "~하던 문제를 고쳤어요"로 써요.
3. 지난주 문의 보고서에서 많이 나온 오류를 고쳤다면 맨 위에 둬요.
4. 앱스토어 문구는 4,000자 제한을 넘지 않게, 첫 세 줄에 핵심을 둬요.

## 쓰지 않는 말
- 내부 코드 이름, 담당자 이름
- "성능 개선" 한 마디로 끝나는 문장(무엇이 얼마나 빨라졌는지 없으면 빼요)
