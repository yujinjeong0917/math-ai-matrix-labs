# 8장 실습. 회귀불연속(RDD)

웹 챕터: https://math-ai-matrix-pi.vercel.app/tracks/causal/08-regression-discontinuity.html

가상 온라인 마켓에서 전월 구매액(x, 만 원)이 10 이상인 고객에게만 쿠폰을 줍니다. 다음 달 주문액에 쿠폰이 만드는 진짜 효과 +10.0(천 원, 가상)을 단순 비교, 전체에 직선 하나, 기준선 근처만 쓰는 국소 선형으로 추정하고, 대역폭(기준선 양쪽에서 얼마나 멀리까지 쓸지)을 바꿔 봅니다. 기준선 직전에 구매액을 채워서 올린 고객이 있을 때 구간별 고객 수와 추정값이 어떻게 변하는지도 봅니다.

## 실행

```bash
cd causal/ch08_regression_discontinuity
python3 rdd.py               # 본문 숫자를 모두 출력 (약 2초)
python3 -m unittest -v       # 출력값을 고정한 검사 (pytest도 가능)
```

표준 라이브러리만 씁니다. 난수는 `random.Random(seed).random()`만 쓰고 정규분포는 직접 만듭니다.

## 기대 출력 (일부)

```
기준선에서 아래쪽 직선 50.0, 위쪽 직선 60.0, 점프 10.0     (바로 붙은 두 구간 차이는 14.0)
단순 비교 19.44 / 전체에 직선 하나 16.81 / 대역폭 1.0 국소 선형 10.63   (진짜 10.0)
200번 반복 평균 오차: 대역폭 0.25 +0.09 (표준편차 1.60) ... 대역폭 8.0 +1.29 (표준편차 0.34)
```

## 이 실습이 확인하지 못하는 것

- 구간별 고객 수는 눈으로 보는 점검일 뿐 McCrary 밀도 검정이나 그 대체 통계량이 아닙니다. 검정 통계량은 구현하지 않았어요.
- 대역폭을 데이터로 고르는 알고리즘(최적 대역폭, 편향 보정, 로버스트 신뢰구간)은 구현하지 않고 고정 값 몇 개를 비교했습니다.
- 사각 커널(대역폭 안은 같은 가중)만 썼고 표준오차와 신뢰구간은 계산하지 않았습니다.
- 기준선에서 쿠폰 외의 다른 것도 같이 바뀌는 경우(복합 처치)와 퍼지 RDD(기준선이 배정 확률만 바꾸는 경우)는 다루지 않았습니다.
- 이 효과는 기준선 근처 고객의 국소 효과입니다. 구매액이 훨씬 높거나 낮은 고객에게 일반화할 수 없어요.
