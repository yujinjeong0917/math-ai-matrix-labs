# 문의 유형 9가지

유형은 아래 9가지만 써요. 한 문의가 두 유형에 걸치면 고객이 먼저 말한 쪽으로 넣어요.

| 유형 | 넣는 문의 | 넣지 않는 문의 |
|---|---|---|
| 배송 | 배송 지연, 배송지 변경, 송장 번호 문의, 일부만 도착 | 상품 파손(교환으로) |
| 환불 | 환불 요청, 환불 금액 확인, 환불 처리 기간 | 결제 실패(결제 오류로) |
| 결제 오류 | 결제 실패, 이중 결제, 결제 수단 등록 오류 | 쿠폰이 결제에 안 붙음(쿠폰으로) |
| 회원 정보 | 로그인, 비밀번호, 탈퇴, 연락처 변경 | 앱이 꺼짐(앱 오류로) |
| 쿠폰 | 쿠폰 미지급, 쿠폰 적용 안 됨, 유효기간 문의 | 적립금(상품 문의로) |
| 앱 오류 | 앱 꺼짐, 화면 멈춤, 알림 안 옴, 업데이트 뒤 오류 | 웹 결제창 오류(결제 오류로) |
| 상품 문의 | 사이즈, 재입고, 소재, 적립금, 사용법 | 받은 상품 불량(교환으로) |
| 교환 | 사이즈 교환, 불량 교환, 파손, 오배송 | 단순 변심 환불(환불로) |
| 칭찬 | 상담원 칭찬, 포장 칭찬, 재구매 의사 | 칭찬과 불만이 섞이면 불만 쪽 유형으로 |

## 예시 분류
- "주문한 지 5일째인데 아직 출발도 안 했어요" → 배송
- "쿠폰을 넣었는데 결제 금액이 그대로예요" → 쿠폰
- "결제는 됐다고 문자가 왔는데 주문 내역에 없어요" → 결제 오류
- "업데이트하고 나서 장바구니 화면이 하얗게 나와요" → 앱 오류
- "M 사이즈가 작아서 L로 바꾸고 싶어요" → 교환
- "상담원분이 끝까지 친절했어요. 그런데 배송은 늦었어요" → 배송(불만이 섞임)

## 기타로 두는 경우
아홉 유형 어디에도 맞지 않으면 "기타"로 두고, 보고서 11절 "이번 주 새로 생긴 유형"에 문의 번호와 한 줄 요약을 적어요. 같은 기타 문의가 3주 연속 5건을 넘으면 새 유형으로 추가할지 팀장에게 물어요.
