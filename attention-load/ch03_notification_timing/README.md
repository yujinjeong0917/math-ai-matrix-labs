# 3장 실습: 알림의 시점을 질문 세 개로 나누기

가상 쇼핑 앱이 주문 입력 중에 보낼 수 있는 알림 8개를 "지금 과제와 관련이 있나, 지금 행동이 필요한가, 놓치면 되돌릴 수 없나" 세 질문으로 나눠 다섯 가지 시점 중 하나에 놓는다. 이 규칙은 이 트랙이 제안한 설계 점검표이고 검증된 규칙이 아니다. 확률과 임계값은 쓰지 않는다.

- 입력: `notifications.json` (가상, 예시용. 알림과 세 질문의 답은 설계자의 손 판단)
- 실행: `python3 notification_timing.py`, 테스트: `python3 -m unittest -v`

기대 출력은 알림 8개의 시점과 아래 개수다.
```
  지금, 화면 안에서: 2
  화면 안에서 조용히: 1
  지금, 과제를 막지 않는 짧은 알림: 1
  주문이 끝난 뒤 묶어서: 2
  보내지 않음(설정에서 켠 사람에게만): 2
```

확인하지 못하는 것: 이 시점 배정이 실제 사용자의 주문 완료, 오류, 놓침에 어떤 영향을 주는지(측정하지 않았다). 세 질문의 답이 사용자마다 달라지는 정도. 마감이 있는 알림(예: 주소를 바꿀 수 있는 시간)을 "끝난 뒤"로 미루면 놓칠 수 있다는 약점은 코드가 잡지 못한다. 알림이 주의를 끊는 정도에 대한 읽은 논문 근거는 없다.
