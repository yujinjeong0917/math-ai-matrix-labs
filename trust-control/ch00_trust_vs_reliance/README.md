# 0장 실습: 믿음이 아니라 따름을 센다 (가상 데이터)

가상 쇼핑몰의 AI 답변 도우미가 낸 답변 10건(7건 맞음, 3건 틀림)에 대해, 사용자 세 명(A 전부 따름, B 가려서 따름, C 전부 거부)의 행동 기록에서 의존율, 적정 신뢰, 과신, 과소신뢰를 계산한다. 모든 숫자는 가상, 예시용이다. 정의와 분모는 이 실습이 정한 것이다(논문이 분모를 이렇게 쓴다고 주장하지 않는다).

- 실행: `python3 reliance.py`, 테스트: `python3 -m unittest -v`

손계산(사용자 B): 맞은 7건 중 6건 따름(1건 안 따름), 틀린 3건 중 1건 따름(2건 안 따름). 의존율 (6+1)/10=70%, 적정 신뢰 (6+2)/10=80%, 과신 1/3=33.3%, 과소신뢰 1/7=14.3%.

기대 출력:
```
[1] 가상 답변 10건 중 AI가 맞은 것 7건 (AI 정확도 70.0%)
[2] 사용자 A: 의존율 100.0%, 적정 신뢰 70.0%, 과신 100.0%, 과소신뢰 0.0%, 칸 {...}
[2] 사용자 B: 의존율 70.0%, 적정 신뢰 80.0%, 과신 33.3%, 과소신뢰 14.3%, 칸 {...}
[2] 사용자 C: 의존율 0.0%, 적정 신뢰 30.0%, 과신 0.0%, 과소신뢰 100.0%, 칸 {...}
```

확인하지 못하는 것: 사용자가 실제로 무엇을 믿었는지(태도)는 기록에서 읽을 수 없다. 10건은 너무 적어 비율이 크게 흔들린다. 신뢰를 시뮬레이션하지 않았고 행동 기록은 손으로 정했다.
