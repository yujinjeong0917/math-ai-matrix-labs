웹 챕터: 인과추론 트랙 2장 「무작위 실험이면 다 끝나나요?」

가상(예시용) 온라인 마켓 장난감 네 개로, 무작위 배정이 맞히는 장면과 틀리는 장면을 진짜 효과와 대조합니다. 난수는 `random.Random(seed).random()`만 쓰며 정확히 절반을 고를 때도 난수 키 정렬을 씁니다.

1. 층화: 단골 120명·일반 280명을 단순 동전 배정과 층별 절반 배정으로 나눠 2,000번 반복하고 효과 추정값의 표준편차(SD)를 비교합니다. 진짜 효과는 +2.0입니다.
2. 군집: 지역 40곳을 지역 단위로 나눌 때, 고객이 독립이라고 가정한 표준오차(SE)가 실제 흔들림보다 얼마나 작은지, 설계 효과 `1 + (m-1)ρ`와 맞는지 봅니다.
3. SRM(표본 비율 불일치): 계획 50:50이 어긋났는지 카이제곱 한 줄로 검사합니다. 처치 쪽에서만 일부 고객 로그가 사라지는 버그가 있을 때 검사가 잡는지와 추정값이 얼마나 틀어지는지 봅니다.
4. 비순응: 쿠폰을 배정받은 사람 중 일부만 쓸 때 ITT(배정 기준 효과), 왈드(ITT÷사용 비율), 사용자와 대조군의 단순 비교를 사용자의 진짜 효과와 대조합니다.

## 실행

```bash
python3 randomized_experiments.py
python3 -m unittest -v
python3 -m pytest -q
```

## 기대 출력

```
1 층화: 단순 배정 평균 2.03, SD 1.05 / 층화 배정 평균 2.00, SD 0.50 (반복 2000, 진짜 2.0)
2 군집: 추정 평균 2.02 / 실제 SD 0.97 / 독립 가정 SE 0.26 / 95% 구간 포함률 0.39 / 설계 효과 14.0 (rho 0.265)
3 SRM(버그 없음): 처치 9983명 대조 10017명 chi2 0.06 p 0.81 추정 0.97 (진짜 1.0)
3 SRM(버그 있음): 처치 8780명 대조 10008명 chi2 80.26 p 3.28e-19 추정 1.86 (진짜 1.0)
4 비순응: ITT 1.48 / 사용 비율 0.551 / 왈드 2.68 / 사용자-대조 비교 4.32 / 사용자의 진짜 효과 2.57
```

## 이 실습이 확인하지 못하는 것

- 장난감의 효과·잡음·사용 확률은 모두 직접 정한 값입니다. 실제 서비스의 잡음 크기나 지역 간 상관은 데이터로 따로 재야 합니다.
- 왈드 추정값이 사용자 효과와 같아지려면 배정이 무작위이고, 배정이 사용 여부를 통하지 않고는 결과에 영향을 주지 않으며, 대조군은 쿠폰을 쓸 수 없다는 조건이 필요합니다. 코드는 이 조건을 만족하도록 만들었을 뿐 현실에서 검정하지 않습니다.
- SRM 검사는 "배정 비율이 이상하다"는 신호만 줍니다. 원인이 어디인지는 알려 주지 않습니다. 경고 기준(p값)은 팀이 정하는 값이며 이 코드는 기준을 정하지 않습니다.
