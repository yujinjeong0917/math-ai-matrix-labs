# 1장 실습: 응답 지연 연구의 조건과 내 화면의 조건 대조하기

Tan 외(2026)의 실험 조건 7항목과 가상 환불 화면, 가상 채팅 답변 도우미의 조건이 같은지 세는 점검표를 만든다. 논문 보고값(사려 깊음 평균, 표준편차, 인원)에서 평균 차이와 7점 척도에 남은 칸, 칸별 인원 합을 다시 계산한다(d 근사와 제외율은 함수와 테스트에 있고 출력에는 넣지 않았다). 모든 숫자는 가상, 예시용이거나 논문 보고값이다.

- 실행: `python3 scope_check.py`, 테스트: `python3 -m unittest -v`
- 출처: doi.org/10.1145/3772318.3790716 과 arXiv:2604.06183 (본문 열람 2026-11-16과 11-17, 서지 확인 2026-11-20). 평균 차이, d, 제외율은 waiting-ux 3장과 4장 실습도 다시 계산한다.

기대 출력:
```
[1] 조건 대조(7항목, 같으면 O)
  가상 환불 진행 화면: 같은 항목 1/7
    지연 종류=X 지연을 만든 방식=X 대기 중 화면=X 과제=X 평가 방식=X 참가자=X 대기 길이(초)=O
  가상 채팅 답변 도우미: 같은 항목 5/7
    지연 종류=O 지연을 만든 방식=X 대기 중 화면=O 과제=O 평가 방식=O 참가자=X 대기 길이(초)=O
[2] 사려 깊음 평균 차이: 2초-9초 0.33점, 2초-20초 0.35점
[3] 7점 척도에서 위로 남은 칸: 2초 1.24, 9초 0.91
[4] 유용성 평균 차이: 2초-9초 0.25점(20초 평균은 값 없음)
[5] 분석 인원 240명(칸 6개 합)
```

확인하지 못하는 것: 같은 항목 수는 효과의 크기나 방향을 예측하지 않는다. 점검표일 뿐이다. d 근사는 두 집단 크기가 같고 공변량이 없다는 가정의 값이고, 유용성은 20초 평균이 논문 본문에 없어 2초와 9초만 비교한다.
