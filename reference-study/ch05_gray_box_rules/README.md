회색 상자 점검(상자 면적 순위가 의도한 중요도 순위와 맞는지)와 크기 비율 옮기기를 가상 화면(도서관 대출 앱, 가상, 예시용)으로 계산합니다. 마지막 두 줄(트랙 목록 화면에 옮겨 보기)만 이 사이트 파일에서 읽은 값입니다. 파이썬 표준 라이브러리만 씁니다.

## 실행

```bash
python3 gray_box.py
python3 -m unittest -q
```

## 이 실습이 확인하지 못하는 것

- "회색 상자 점검"는 제안된 연습법이고 효과가 입증된 기준이 아닙니다. 면적 순위와 중요도가 맞아도 좋은 화면이라는 뜻은 아니에요.
- 면적 외에 위치, 색, 글자 크기가 위계에 주는 영향은 계산하지 않습니다.
- 비율이 비슷하면 규칙을 가져온 것이라는 판정은 하지 않습니다. 비율 차이는 참고 숫자예요.
