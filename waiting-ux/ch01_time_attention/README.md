Wang, Si & Ali (2025)의 실험 1·2에 적힌 평균, SD, F, 매개 계수로 d, η², 간접효과 a×b, 직접효과와 간접효과의 합을 직접 계산한다. 시간 지각을 흉내 내지 않는다.

- 실행: `python3 attention_check.py`, 테스트: `python3 -m unittest -v`
- 출처: doi.org/10.3390/jtaer20040306 (MDPI 공개본), 2026-11-18 확인.

기대 출력:
```
실험 1: 합친 SD 1.056, 평균 차이 -0.90, 평균·SD에서 구한 d=-0.85
실험 2: 합친 SD 1.186, 평균 차이 -1.15, 평균·SD에서 구한 d=-0.97
실험 1 보고 F=24.38에서: η²=0.111(논문 보고 0.12), 거꾸로 구한 d=0.71
실험 2 보고 F=35.88에서: η²=0.081(논문 보고 0.08), 거꾸로 구한 d=0.59
실험 1 평균·SD와 집단 크기 99/99로 다시 만든 값: F=36.0(보고 24.38), η²=0.155, d=-0.85
실험 2 평균·SD와 집단 크기 205/206로 다시 만든 값: F=96.6(보고 35.88), η²=0.191, d=-0.97
실험 2 매개: a×b=-0.5904(논문 -0.59), c'+ab=-0.6804, 평균 차이 -1.15, 어긋남 -0.47
```

"다시 만든 값"은 보고된 평균·SD와 집단 크기로 다시 계산한 값이고, 두 집단 크기를 같게(또는 205/206처럼 거의 같게) 가정하고 공변량 통제는 넣지 않았다(실험 1은 198명을 99/99, 실험 2는 411명을 205/206). 논문의 보고 F와 η²가 평균·SD·인원에서 계산한 값과 크게 다른 이유(집단 크기 차이, 공변량 통제, 평균과 SD의 반올림, 보고 오류 등)는 알 수 없다.

이 실습이 다루지 않는 것: SD를 두 집단 크기가 같다고 보고 단순 제곱 평균으로 합쳤다(근사). 논문 표 1과 부록은 읽은 텍스트에 없다. 거꾸로 구한 d는 d=2t/√df(집단 크기가 같다고 가정)다. 실험 2에서 직접효과와 간접효과의 합이 평균 차이와 안 맞는 이유(코딩, 공변량 등)는 알 수 없다.
