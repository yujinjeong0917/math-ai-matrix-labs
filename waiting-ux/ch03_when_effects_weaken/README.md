Wang 외(2025) 실험 3·4의 칸 평균에서 "정적 마이너스 동적" 차이와 그 차이의 차이를 계산하고, 2×2 설계의 오차 자유도를 검산한다. Tan 외(2026)의 지연을 느낀 인원 비율과 사려 깊음 평균 차이도 같은 방식으로 다시 계산한다.

- 실행: `python3 moderation_check.py`, 테스트: `python3 -m unittest -v`
- 출처: doi.org/10.3390/jtaer20040306 (2026-11-18 확인), doi.org/10.1145/3772318.3790716 및 arXiv:2604.06183 (2026-11-18 확인).

기대 출력:
```
실험 3 몰입: 정적-동적 차이 낮은 몰입 1.71, 높은 몰입 0.43, 차이의 차이 1.28
실험 4 목적: 정적-동적 차이 쾌락 0.90, 실용 0.20, 차이의 차이 0.70
2×2, N=400이면 오차 자유도 396 (논문: 실험 3 398, 실험 4 396)
실험 3 조건부 간접효과 차이 0.341, 논문 보고 지수 0.432
실험 4 조건부 간접효과 차이 0.409, 논문 보고 지수 0.527
Tan 지연을 느꼈다 2초: 21/79 = 26.6%
Tan 지연을 느꼈다 9초: 53/80 = 66.3%
Tan 지연을 느꼈다 20초: 66/81 = 81.5%
Tan 사려 깊음 2초 대 9초 차이 0.33점, d=0.31
Tan 사려 깊음 2초 대 20초 차이 0.35점, d=0.34
Tan 유용성 2초 대 9초 차이 0.25점
```

확인하지 못하는 것: 논문이 보고한 조절된 매개 지수는 조건부 간접효과의 차이(조절 변수를 0/1로 코딩했다고 가정해 다시 만든 값)와 달라서 인용하지 않았다. 원인은 알 수 없다(코딩, 공변량, 반올림, 보고 오류 가능성). 실험 3의 분모 자유도 398은 논문에 그렇게 적혀 있고 이유를 알 수 없다. Tan 외의 칸별(과제 유형별) 비율은 인원과 정수로 맞지 않아 합친 값만 썼다. d는 두 집단 크기가 같다고 가정하고 두 SD의 제곱 평균을 쓴 근사(공변량 없음)다. 유용성은 SD가 없어 평균 차이만 낸다.
