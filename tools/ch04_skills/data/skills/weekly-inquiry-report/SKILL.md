# 주간 고객 문의 보고서

## 순서
1. 문의 파일을 받으면 먼저 `scripts/count_by_type.py`를 돌려 유형별 건수를 얻어요. 건수를 직접 세지 않아요.
2. 유형 이름은 `references/categories.md`의 9가지만 써요. 어디에도 맞지 않으면 "기타"로 두고 보고서 11절에 따로 적어요.
3. 보고서 양식은 `references/template.md`를 따라요. 절 순서를 바꾸지 않아요.
4. 각 절은 건수, 대표 문의 2건(문의 번호 포함), 할 일 한 줄 순서로 써요.
5. 고객 이름, 전화번호, 주소는 보고서에 옮기지 않아요. 문의 번호만 써요.
6. 같은 고객이 같은 내용을 여러 번 보냈으면 1건으로 세고, 그 사실을 대표 문의 옆에 적어요.

## 말투
- 해요체로 쓰고, 한 문장은 60자 안팎으로 끊어요.
- "급증", "폭주" 같은 말 대신 지난주 대비 숫자를 써요. 예: 환불 문의 18건, 지난주보다 6건 많아요.
- 추측은 "~로 보여요"라고 쓰고, 근거가 된 문의 번호를 붙여요.

## 마지막 확인
- 유형별 건수의 합이 전체 문의 수와 같은지 확인해요.
- 10절 불만 상위 5는 건수가 같으면 최근 접수 순으로 놓아요.
- 12절 다음 주 할 일은 담당 팀 이름을 붙여 3개 이하로 써요.
