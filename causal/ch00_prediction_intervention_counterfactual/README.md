웹 챕터: 인과추론 트랙 0장 「매출이 올랐으면 새 기능 덕분일까요?」

가상(예시용) 온라인 마켓 장난감에서 진짜 효과를 알고 있을 때, 세 가지 읽기가 얼마나 맞는지 잽니다. 난수는 `random.Random(seed).random()`만 쓰고 표준정규는 Box-Muller로 만들어서, 파이썬 버전이 달라도 같은 숫자가 나옵니다.

- 장면 A: 위젯을 본 사람과 안 본 사람의 주문 격차(예측에 쓰는 관찰 격차)와, 위젯 노출을 동전으로 정했을 때의 격차(개입 효과)를 비교합니다. 진짜 효과는 월 0.3건입니다.
- 장면 B: 도입 전 8주와 도입 후 8주를 단순 비교한 값과, 1년 전 같은 8주 창의 전후 변화를 한 번 더 뺀 효과 어림값(작년 같은 주를 뺀 값)을 비교합니다. 진짜 효과는 주당 +5입니다. 같은 주에 광고 증액(+12)이 겹치면 효과 어림값이 어떻게 틀리는지도 봅니다.

## 실행

```bash
python3 prediction_vs_intervention.py
python3 -m unittest -v
python3 -m pytest -q
```

## 기대 출력

```
A 위젯: 관찰 격차 2.29 / 동전 배정 격차 0.27 / 진짜 0.30 (본 사람 10000명, 안 본 사람 10000명)
B 기능, 광고 증액 +0: 단순 전후 15.01 / 효과 어림값(작년 같은 주를 뺌) 4.46 / 진짜 5.0 / 계절 곡선만의 상승 10.56
  올해 전 112.83 후 127.84 / 작년 전 102.43 후 112.97 / 작년 같은 주 변화 10.55
B 기능, 광고 증액 +12: 단순 전후 27.01 / 효과 어림값(작년 같은 주를 뺌) 16.46 / 진짜 5.0 / 계절 곡선만의 상승 10.56
  올해 전 112.83 후 139.84 / 작년 전 102.43 후 112.97 / 작년 같은 주 변화 10.55
```

## 이 실습이 확인하지 못하는 것

- 장난감 데이터라서 실제 주문 데이터의 요일 효과, 휴일, 재고 부족은 들어 있지 않습니다.
- 작년 같은 주를 빼는 방법은 "올해 같은 주 창의 계절 변화가 작년과 같다"는 단순한 가정을 씁니다. 이 가정이 맞는지는 도입 전 구간에서만 점검할 수 있습니다.
- 같은 주에 겹친 사건이 있어도 데이터만 보고는 그 사건의 몫을 따로 떼어 낼 수 없다는 점을 보일 뿐, 해결 방법은 보여 주지 않습니다.

- 화면에 찍힌 평균(소수 둘째 자리 반올림)끼리 빼면 계산한 값과 0.01 어긋날 수 있습니다. 예: 112.97 - 102.43 = 10.54지만 반올림 전 값의 차이는 10.55입니다.
