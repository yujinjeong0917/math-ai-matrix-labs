# 4장 실습: 조건 장부, 실험이 다룬 조건과 내 화면의 조건 대조 (가상 화면)

Wang & Yin(2022)의 세 실험이 서로 어느 칸에서 다른지(과제, 데이터, 특징 수, 모델, 정확도, AUC, 훈련 과제, 보수)를 세고, 가상 쇼핑몰 답변 도우미 화면의 조건이 실험이 다룬 값 목록 안에 있는지 확인한다. 실험 조건은 논문 본문 표에서 옮겼고 None은 읽은 범위에서 찾지 못한 칸이다. 화면 조건은 가상, 예시용이다. 같은 값인지만 세고 비슷한지는 판단하지 않는다.

- 실행: `python3 condition_ledger.py`, 테스트: `python3 -m unittest -v`

손계산: 실험 1과 2를 칸별로 비교한다. 과제(재범 대 산림), 데이터(COMPAS 대 UCI), 특징 수(7 대 8), 정확도(69.1 대 69.5), AUC(0.749 대 0.686), 훈련 과제(0 대 10), 기본 보수(1.80 대 2.00)가 다르고 모델(둘 다 로지스틱 회귀)만 같아 7칸이 다르다.

기대 출력:
```
[1] 실험 1과 2가 다른 칸 7개: ['과제', '데이터', '특징 수', '모델 정확도(%)', '모델 AUC', '훈련 과제 수', '기본 보수(달러)']
[2] 실험 1과 3이 다른 칸 3개: ['모델', '모델 정확도(%)', '모델 AUC'] / 읽은 범위에서 값을 모르는 칸 2개: ['훈련 과제 수', '기본 보수(달러)']
[3] 가상 쇼핑몰 화면: 차원 7개 중 실험이 다룬 것 1개 ['재는 결과'], 다루지 않은 것 6개 [...]
```

확인하지 못하는 것: 실험 3의 훈련 과제 수와 보수는 읽은 범위에서 찾지 못해 비교하지 못했다. 실험 1과 3은 설명 처치 목록도 다르다(기여도 하나 대 LIME과 SHAP 둘). 이 장부는 "다르다"만 보여 주고 어느 칸이 효과 차이를 만들었는지는 알려 주지 못한다.
