# 12장. 식으로 못 풀면 무엇을 할까

시간대별 도착률(처음 2시간 분당 0.36건, 이후 0.16건)과 로그정규 처리 시간(평균 5분)인 상담 센터를 사건 목록(heapq)으로 시뮬레이션합니다. 닫힌 식이 없는 조건입니다. 엔진은 먼저 M/M/1에서 이론값과 대조해 검증한 뒤 씁니다. 8시간 근무를 시드 1~20으로 20번 반복하고 95% 신뢰구간(t 임계값 2.093)을 냅니다. 숫자는 학습용 가상값입니다.

```bash
python3 simulation.py
python3 -m unittest -v
```

## 기대 출력(요약)

- 엔진 검증: M/M/1 이용률 0.8에서 시뮬레이션 19.71분, 이론 20.00분
- 상담원 2명, 한 번만 돌린 평균 대기: 시드별 0.62분부터 13.98분까지
- 20회 평균 대기 3.77분(95% 구간 2.20~5.34), 상담원 3명이면 0.58분(0.28~0.88)
- 같은 난수로 짝지어 뺀 차이 3.19분(1.88~4.49), 난수를 따로 쓰면 3.38분(1.78~4.97)

## 이 실습이 확인하지 못하는 것

- 입력 분포(도착률·처리 시간)는 가정이며 실제 로그로 맞추지 않았습니다.
- 매일 아침 비어 있는 상태에서 시작하는 가정이라 전날 밀린 문의는 없습니다.
- t 구간은 반복 결과가 대략 대칭이라 가정합니다. 이 실습처럼 한쪽으로 치우친 값(예: 비율이 0에 몰릴 때)에서는 구간 하한이 0 아래로 내려갈 수 있어 그대로 믿으면 안 됩니다.
- 시뮬레이션이 최적 인원을 골라 주지는 않습니다. 후보를 하나씩 돌려 비교할 뿐입니다.
