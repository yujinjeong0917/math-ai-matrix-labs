# 0장 실습: 같은 화면이 사용자마다 다르게 쓰이는 것을 세어 보기

가상 쇼핑 앱 주문 입력 화면의 요소 10개를 두 가상 사용자(첫 구매자, 단골)에게 "지금 결정해야 함 / 확인만 하면 됨 / 지금 과제와 무관"으로 나눈 손 분류를 읽어 개수를 센다. 분류는 설계자가 붙인 예시용 값이고 사람을 측정한 결과가 아니다.

- 입력: `order_screen.json` (요소 이름과 두 사용자별 분류. 직접 고쳐 보면 개수가 바뀐다)
- 실행: `python3 attention_audit.py`, 테스트: `python3 -m unittest -v`
- 이 코드에는 "몇 개를 넘으면 많다" 같은 기준이 없다. 세기만 한다.

기대 출력:
```
[1] 첫 구매자: 결정 6, 확인 3, 무관 1 (합 10)
[2] 단골: 결정 3, 확인 3, 무관 4 (합 10)
[3] 두 사용자에서 분류가 다른 요소: 5개 / 10개 (배송지, 결제 수단, 쿠폰 입력, 배송 안내 문구, 리뷰 별점 요약)
[4] 두 사용자 모두 '무관'인 요소: 추천 배너
```

확인하지 못하는 것: 분류가 실제 사용자 눈에도 그렇게 보이는지(사람을 관찰하지 않았다). "무관"인 요소가 나쁜 요소인지(안심 문구처럼 도움이 될 수 있다). 요소 개수와 주의, 머리 부담 사이의 관계(이 코드는 어떤 관계도 가정하지 않는다). Wang 외(2025)의 로딩 화면 결과가 주문 입력 화면에서도 나오는지.
