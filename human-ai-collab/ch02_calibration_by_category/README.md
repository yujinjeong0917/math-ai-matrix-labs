# 2장 실습: 문의 유형별, 달별로 정답률과 수락률의 격차 세기

가상 고객지원 팀의 AI 답변 제안을 문의 유형 4개(환불, 배송, 계정, 결제)와 두 달(1개월 차, 3개월 차)로 나눠 20건씩 적은 고정 표(`LOG`)에서 유형별 정답률, 수락률, 격차(수락률-정답률, 퍼센트포인트), 유형별 수락률 범위와 정답률 범위의 비율을 센다. 가상 시나리오는 2개월 차에 배송 안내 정책이 바뀌어 배송 제안이 자주 틀리기 시작했다는 것이다. 모든 숫자는 가상, 예시용이다. 신뢰를 모형으로 만들지 않았다. 보정, 해상도, 특정성은 Lee & See(2004)의 개념이고, 격차와 범위 비율은 이 장이 정한 거친 대용값이며 그 논문의 측정 절차가 아니다. 수락률은 행동(의존)이다.

- 실행: `python3 calibration.py`, 테스트: `python3 -B -m unittest -v`

손계산(가상, 예시용): 배송 1개월 차는 정답 16/20=80%, 수락 14/20=70%라 격차 -10p. 배송 3개월 차는 정답 10/20=50%, 수락 15/20=75%라 격차 +25p. 3개월 차 전체는 정답 18+10+12+9=49건/80건=61.25%, 수락 16+15+13+12=56건/80건=70%. 1개월 차 전체는 정답 51/80=63.75%, 수락 56/80=70%. 범위 비율은 1개월 차 (75-65)/(85-40)=10/45=0.22, 3개월 차 (80-60)/(90-45)=20/45=0.44.

기대 출력:
```
[1개월 차]
  환불: 정답 17/20 = 85%, 수락 15/20 = 75%, 격차 -10.0p
  배송: 정답 16/20 = 80%, 수락 14/20 = 70%, 격차 -10.0p
  계정: 정답 10/20 = 50%, 수락 14/20 = 70%, 격차 +20.0p
  결제: 정답 8/20 = 40%, 수락 13/20 = 65%, 격차 +25.0p
  전체: 정답률 63.75%, 수락률 70.00%, 격차 +6.25p, 범위 비율 0.22
[3개월 차]
  환불: 정답 18/20 = 90%, 수락 16/20 = 80%, 격차 -10.0p
  배송: 정답 10/20 = 50%, 수락 15/20 = 75%, 격차 +25.0p
  계정: 정답 12/20 = 60%, 수락 13/20 = 65%, 격차 +5.0p
  결제: 정답 9/20 = 45%, 수락 12/20 = 60%, 격차 +15.0p
  전체: 정답률 61.25%, 수락률 70.00%, 격차 +8.75p, 범위 비율 0.44
```

확인하지 못하는 것: 유형당 20건이라 한 칸의 차이는 우연일 수 있고 구간을 계산하지 않았다. 수락률과 정답률을 같은 눈금에 놓는 것은 거친 비교이며 제안 하나하나의 적정 의존(1장)과 같지 않다. 정답 판정 절차는 정하지 않았다. 범위 비율이 올랐다고 상담원이 배웠다고 읽을 수 없다.
