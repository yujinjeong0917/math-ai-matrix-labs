# 환불 답장 초안

## 순서
1. 주문일, 받은 날, 상품 상태(개봉 여부), 결제 수단을 문의에서 찾아요. 없으면 답장에 묻는 문장을 넣어요.
2. `references/refund-policy.md`의 표에서 경우를 하나 고르고, 그 줄의 처리 기간과 금액 계산을 그대로 써요.
3. 환불이 안 되는 경우에도 첫 문장은 사과나 공감으로 시작하고, 둘째 문장에 이유를, 셋째 문장에 할 수 있는 다른 방법(교환, 적립금)을 써요.
4. 금액은 원 단위까지 쓰고, 계산식을 괄호로 한 번 보여 줘요.

## 쓰지 않는 말
- "규정상 불가합니다"처럼 규정 뒤에 숨는 말
- 확인하지 않은 처리 날짜 약속
- 다른 고객 사례

## 마지막 확인
- 답장에 고객 이름은 한 번만, 주문 번호는 꼭 넣어요.
- 300자를 넘으면 문단을 나눠요.
