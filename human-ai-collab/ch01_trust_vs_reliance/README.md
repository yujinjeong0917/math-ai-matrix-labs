# 1장 실습: 신뢰(태도)와 의존(행동)을 나눠 오용, 불용, 적정 의존 세기

가상 상담원 4명이 한 달 동안 AI 답변 제안을 20건씩 본 기록(AI가 맞았나 x 받아들였나)과 같은 달 설문의 "AI를 믿는 정도" 1~5점 한 문항을 손으로 적은 고정 표(`AGENTS`)로 둔다. 코드는 수락률, 오용 비율, 불용 비율, 적정 의존 비율을 세고, 설문 순위와 수락률 순위의 차이를 본다. 모든 숫자는 가상, 예시용이다. 신뢰를 모형으로 만들어 숫자를 뽑지 않았다. 오용, 불용, 적정 의존의 계산식은 이 장이 정한 측정 방식이고, Lee & See(2004)가 정한 측정 절차가 아니다(그 논문은 개념을 주고 측정 절차는 주지 않는다).

- 실행: `python3 reliance_log.py`, 테스트: `python3 -B -m unittest -v`

손계산(가상, 예시용): 상담원 가는 AI 맞음+수락 12건, 맞음+수정 2건, 틀림+수락 1건, 틀림+수정 5건이다. 수락은 12+1=13건이라 13/20=65%. 틀린 제안은 1+5=6건이고 그중 받아들인 것이 1건이라 오용 1/6=16.7%. 맞은 제안은 12+2=14건이고 그중 고친 것이 2건이라 불용 2/14=14.3%. 맞은 것을 받아들이고 틀린 것을 고친 것은 12+5=17건이라 적정 17/20=85%.

본문의 스스로 점검 1번(가상): 틀린 제안 10건 중 3건을 받아들였다면 3/10=30%.

기대 출력:
```
  가: 수락 13건 = 65%, 오용 16.7%, 불용 14.3%, 적정 85%, 설문 4점
  나: 수락 9건 = 45%, 오용 16.7%, 불용 42.9%, 적정 65%, 설문 5점
  다: 수락 16건 = 80%, 오용 62.5%, 불용 8.3%, 적정 70%, 설문 2점
  라: 수락 11건 = 55%, 오용 25.0%, 불용 25.0%, 적정 75%, 설문 3점
[2] 설문 순위와 수락률 순위의 차이: 가 0, 나 3, 다 3, 라 0
[3] 네 명 합계: {'CA': 40, 'CO': 12, 'WA': 9, 'WO': 19} 수락률 61.3%
```

확인하지 못하는 것: 상담원 4명에 한 달 기록이라 어떤 통계적 추정도 하지 않는다. 설문 한 문항은 신뢰를 대표하지 않는다. 틀림과 맞음은 이 장이 가정한 정답 표시이고 현장에서는 별도 판정 절차가 필요하다. 수락하지 않은 이유(자신감, 작업 부하 등)는 기록에 없다.
