# 금지어와 바꿀 말

| 쓰지 않는 말 | 바꿀 말 | 이유 |
|---|---|---|
| 실패하였습니다 | ~하지 못했어요 | 딱딱한 말투 |
| 잘못 입력하셨습니다 | ~를 다시 확인해 주세요 | 고객 탓으로 들림 |
| 확인 | 저장하기, 보내기처럼 하는 일 | 무엇을 하는 버튼인지 모름 |
| 오류가 발생했습니다 | 무엇이 안 됐는지 + 할 일 | 정보가 없음 |
| 해당 | 그, 이 | 사무 문서 말투 |
| 진행하시겠습니까? | ~할까요? | 길고 딱딱함 |
| 회원님 | 고객 이름 또는 생략 | 화면마다 호칭이 다름 |
| 처리 중입니다 | ~하고 있어요 | 딱딱한 말투 |
| 불가합니다 | ~할 수 없어요 + 다른 방법 | 막다른 길로 들림 |
| 클릭 | 누르기 | 휴대폰에서는 누름 |

## 숫자와 단위
- 금액은 쉼표를 넣고 "원"을 붙여요(6,000원).
- 기간은 "영업일 3일"처럼 단위를 함께 써요.
- 시각은 24시간제로 써요(14:30).
