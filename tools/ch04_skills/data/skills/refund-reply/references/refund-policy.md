# 환불 규정 요약 (팀 내부용, 2026년 하반기)

| 경우 | 환불 여부 | 처리 기간 | 금액 |
|---|---|---|---|
| 받은 지 7일 이내, 미개봉 | 전액 | 영업일 3일 | 결제 금액 전체 |
| 받은 지 7일 이내, 개봉, 단순 변심 | 부분 | 영업일 3일 | 결제 금액 - 왕복 배송비 6,000원 |
| 받은 지 7일 이후, 단순 변심 | 불가 | - | 교환 또는 적립금 안내 |
| 상품 불량, 오배송 | 전액 | 영업일 2일 | 결제 금액 전체, 배송비 회사 부담 |
| 배송 전 주문 취소 | 전액 | 즉시~영업일 1일 | 결제 금액 전체 |
| 쿠폰을 쓴 주문 | 쿠폰 금액 제외 | 위와 같음 | 쿠폰은 유효기간이 남았으면 다시 지급 |

## 결제 수단별 실제 입금
- 카드: 카드사 사정으로 영업일 3~5일 더 걸릴 수 있어요.
- 계좌이체: 처리 기간 안에 입금해요.
- 적립금: 즉시 돌려줘요.

## 자주 틀리는 계산
- 부분 환불에서 배송비를 한 번(3,000원)만 빼는 실수. 왕복이라 6,000원이에요.
- 쿠폰을 쓴 주문에서 쿠폰 금액까지 돌려주는 실수.
