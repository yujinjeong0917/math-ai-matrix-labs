# 설문 요약

## 순서
1. 응답 수와 기간을 먼저 써요.
2. 0~10점 문항은 9~10점 비율에서 0~6점 비율을 빼서 NPS를 계산하고, 계산식을 함께 보여 줘요.
3. 주관식은 비슷한 것끼리 묶어 주제 5개 이하로 정리하고, 주제마다 응답 수와 대표 응답 1개를 붙여요.
4. 응답이 30개보다 적으면 비율 대신 건수로 써요.

## 쓰지 않는 말
- 응답 수 없이 비율만 쓴 문장
- 대표 응답을 고쳐 쓴 문장(원문 그대로 옮겨요)
