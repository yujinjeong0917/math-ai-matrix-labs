# 2장. 기계 한 시간이 더 생기면 얼마의 가치가 있나

1장과 같은 가상 선형계획에서 쌍대 변수(그림자가격)를 두 길로 확인합니다. (1) 제약의 우변을 바꿔 다시 풀어 최적값 곡선의 기울기와 꺾이는 지점을 찾고, (2) 쌍대 인증서(`A^T y >= c`, `y >= 0`, 쓰고 남는 제약의 `y = 0`, `b·y = 최적값`)를 검사합니다.

## 실행

```bash
cd or/ch02_shadow_price
python3 shadow_price.py
python3 -m unittest -v
```

## 기대 출력 (핵심)

```
한 시간 증분(재봉/포장/주문한도): ['1', '1', '0']
쌍대 인증서 y=(1,1,0): [True, True, '180', '180']
기울기가 바뀌는 b1: [(80, '2', '1'), (120, '1', '0')]
포장 시간 b2: 기울기가 바뀌는 지점: [(60, '2', '1'), (100, '1', '0')]
y=(2,0,0): [True, True, '200', '180']
```

## 확인하지 못하는 것

- 퇴화(최적 꼭짓점에서 제약이 셋 이상 만나는 경우)에서는 그림자가격이 하나로 정해지지 않을 수 있습니다. 이 예제는 퇴화하지 않습니다.
- 정수 변수가 있으면 그림자가격이 그대로 성립하지 않습니다(5장).
- 시간을 실제로 살 수 있는지, 얼마에 사는지는 모형 밖의 일입니다.
