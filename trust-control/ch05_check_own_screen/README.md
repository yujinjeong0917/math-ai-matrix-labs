# 5장 실습: 두 화면 비교의 집계, 구간, 가이드 표 점검 (가상 데이터)

가상 쇼핑몰 답변 도우미의 두 화면(A 답변만, B 답변과 근거 문장)을 참가자 12명씩 비교하는 상황을 가정한다. 참가자마다 AI 답변 16건(맞는 답변 8건, 틀린 답변 8건으로 설계)을 보고, 맞는 답변 중 따른 건수와 틀린 답변 중 따른 건수가 기록이다. 과신, 과소신뢰, 적정 신뢰를 참가자별로 구해 화면 평균 차이와 참가자를 다시 뽑는 부트스트랩 95% 구간(2000번, 시드 20)을 낸다. 가이드 표 7줄(조건, 대상, 이유, 근거, 강도)이 다섯 칸을 갖췄는지도 검사한다. 모든 숫자는 가상, 예시용이고 기록은 손으로 정한 값이다(사람의 행동을 시뮬레이션하지 않았다).

- 실행: `python3 own_screen.py`, 테스트: `python3 -m unittest -v`

손계산: 참가자 한 명이 맞는 답변 8건 중 6건, 틀린 답변 8건 중 4건을 따랐다면 과신 4/8=50%, 과소신뢰 2/8=25%, 적정 신뢰 (6+4)/16=62.5%. 화면 A의 맞는 답변 따름 합계는 73건이라 과소신뢰 평균이 (96-73)/96=24.0%이고, 틀린 답변 따름 합계는 49건이라 과신 평균은 49/96=51.0%, 화면 B는 67건이라 67/96=69.8%, 차이 18.8%p.

기대 출력:
```
[1] 가상 참가자: 화면 A 12명, 화면 B 12명, 각자 AI 답변 16건
[2] 과신: A 평균 51.0%, B 평균 69.8%, 차이(B-A) 18.8%p, 95% 구간 [12.5, 25.0]%p
[2] 과소신뢰: A 평균 24.0%, B 평균 5.2%, 차이(B-A) -18.8%p, 95% 구간 [-25.0, -12.5]%p
[2] 적정 신뢰: A 평균 62.5%, B 평균 62.5%, 차이(B-A) 0.0%p, 95% 구간 [-2.1, 2.1]%p
[3] 가이드 표 7줄 검사: 통과 7줄
```

확인하지 못하는 것: 가상 기록은 "합계 점수는 같은데 오류 구성이 달라지는 경우"를 보이려고 손으로 정했다. 실제 화면에서 이런 결과가 나온다는 근거가 아니다. 12명은 작은 규모이고, 가이드 표 검사는 칸이 채워졌는지와 강도가 네 가지 중 하나인지만 보며 내용이 옳은지는 보지 않는다.
