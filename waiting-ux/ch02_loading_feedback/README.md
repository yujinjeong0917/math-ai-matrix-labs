15초 대기 화면을 60Hz에서 그릴 때의 프레임 수, 고리의 프레임당 회전각, 진행 막대 채움 규칙을 계산하고, Wang 외(2025)가 실험마다 바꾼 것(실험 1, 2는 움직임 유무, 실험 3, 4는 움직임 유무와 지시문)과 Fang 외(2022)가 바꾼 것(진행 정보 유무, 만화 장식, 음악)을 목록으로 적어 둔다. 목록을 코드에 적어 두면 장의 문장과 어긋나는지 점검하기 쉽다. 속도와 프레임은 가상, 예시용이다.

- 실행: `python3 feedback_spec.py`, 테스트: `python3 -m unittest -v`

기대 출력:
```
15초 = 900프레임(60Hz)
1초에 한 바퀴 도는 고리: 프레임당 6.0도, 15초 동안 15바퀴
15초에 걸쳐 채우는 막대: 7.5초에 50%
200ms = 12프레임, 16.7ms = 1프레임
Fang 외가 바꾼 것 3가지, 두 논문이 바꾸지 않은 것 ['스켈레톤 화면', '스피너와 진행 막대의 직접 비교']
Wang 외 실험 1(N=198): 바꾼 것 움직임 유무
Wang 외 실험 2(N=411): 바꾼 것 움직임 유무
Wang 외 실험 3(N=400): 바꾼 것 움직임 유무, 과제 몰입 지시문
Wang 외 실험 4(N=400): 바꾼 것 움직임 유무, 탐색 목적 지시문
Fang 외 장식 F=1.108, 자유도 (1,21)의 p=0.304(본문은 0.034, 표는 0.304)
Fang 외 쌍 비교 예: (-1×1 + 1×16 + 0×6) / 23 = 0.65
```

Fang 외 줄: 논문의 장식 효과 F=1.108(오차 자유도 21)에서 이 실습이 계산한 p는 약 0.304로 표의 값과 같고, 본문의 0.034와는 다르다. 두 값은 불일치의 증거로만 보이며 효과의 근거로 인용하지 않는다. 쌍 비교 예의 응답(A 1명, B 16명, 같다 6명)은 논문이 적은 값이다.

이 실습이 다루지 않는 것: 어떤 모양이 더 짧게 느껴지는지는 계산하지 않는다. 스켈레톤, 진행 막대 종류, 속도에 대한 근거는 이 실습에도 읽은 논문에도 없다. 쌍 비교를 동시에 보였는지 연달아 보였는지는 정하지 않았다.
