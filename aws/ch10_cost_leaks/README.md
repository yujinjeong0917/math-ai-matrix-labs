# 10장 · 청구서는 요청 수가 아니라 어디에서 커질까요?

유휴 시간, 시작할 때 내려받는 데이터, 로그 보관 기간, 남은 이전 버전을 단가 없이 수량(시간·GB)으로 셉니다. 단가는 독자가 AWS Pricing Calculator에서 확인해 `unit_prices`에 넣어야 금액이 나오고, 비어 있으면 그 줄은 HOLD예요. 1GB는 10^9바이트입니다.

## 실행

```bash
python3 cost_inputs.py cost_profile.json
python3 -m unittest -v
```

## 기대 출력(발췌)

```
[small] 하루 20건
  작업자 1개, 켜 둔 시간 720시간/월, 놀고 있는 비율 0.993
[scaled] 하루 20000건
  작업자 14개, 켜 둔 시간 10080시간/월, 놀고 있는 비율 0.504
  프롬프트 전체 로그 0.4000GB/일, 메타데이터만 0.01000GB/일
  로그 저장량: 보관 30일이면 12.000GB, 만료 없이 12개월이면 144.000GB
  NAT로 내려받는 모델 280.98GB/월, 인터넷으로 나가는 응답 1.800GB/월
  모델 버전 저장 46.830GB -> 수명주기 후 14.049GB
  컨테이너 이미지 저장 60GB -> 수명주기 후 18GB
```

## 이 실습이 확인하지 못하는 것

- 가격은 어디에도 없습니다. 테스트의 단가 2.0은 곱셈 확인용 가짜 숫자예요.
- 한 달 시작 횟수 60번, 목표 사용률 50%, 응답·로그 바이트는 가상 값입니다.
- 모델 파일이 NAT를 지나는지는 내 구성에서 따로 확인해야 해요.
- 데이터 전송의 방향별 요금 여부는 확인하지 않았습니다.
- 한도·요금 항목 근거는 장 본문의 공식 문서 목록(2026-11-14 확인)에 있어요.
