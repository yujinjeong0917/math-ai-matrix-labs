# 8장. 교대 근무: 규칙과 희망을 같이 지키는 일정

무엇을 재나: 4명, 7일, 낮 2명 + 야간 1명 교대표를 하드 제약(야간 후 휴식, 연속 근무 3일 이하, 주 6일 이하, 야간 2번 이하)과 휴무 희망 벌점으로 풀고, 가지치기 유무·독립 검사기·작은 크기 전수 탐색으로 대조한다. 숫자는 모두 예시용이다. 이 코드는 OR-Tools CP-SAT이 아니라, 제약 프로그래밍의 생각을 작게 재현한 역추적 탐색이다.

실행(이 폴더 안에서):

```bash
python3 -m unittest -v
python3 shift_scheduling.py
```

기대 출력(요약):

- 첫 가능 일정: 노드 15, 벌점 5
- 벌점 최소: 4, 가지치기 노드 301 (가지치기 없이 421, 규칙을 지키는 일정 총 48개)
- 연속 근무 상한을 4로 풀면 최소 벌점 3(벌점 하한과 같음). 근무일·야간 상한을 풀어서는 4 그대로
- 주 근무 상한 5(노드 373), 야간 상한 1(145), 연속 근무 2(49)는 모두 불가능

확인하지 못하는 것: 실제 근무 규정(법령·취업규칙), 근무 시간 길이·자격, 공정성 지표, 큰 크기에서의 속도, CP-SAT 결과와의 비교. 실행 시간은 기기마다 달라 기록하지 않았다.
