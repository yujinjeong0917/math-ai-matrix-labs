# 5장 실습: 문의 구성이 바뀐 두 달의 해결률 읽기와 기록 열 점검

가상 고객지원 팀의 두 달(1개월 차, 3개월 차) 문의를 난이도(쉬움, 어려움)로 나눠 문의 수와 한 번에 해결한 수를 손으로 적은 고정 표(`TICKETS`)로 두고, 전체 해결률과 난이도별 해결률, 문의 구성 비중, 구성을 1개월 차에 맞춘 해결률을 센다. 가상 시나리오는 3개월 차에 쉬운 문의가 늘었다는 것이다. 이어서 기록 열 집합(`MINIMAL`, `FULL`)으로 여섯 가지 질문에 답할 수 있는지 점검한다. 모든 숫자는 가상, 예시용이다. 팀 성과를 모형으로 흉내 내지 않았다.

- 실행: `python3 reading_months.py`, 테스트: `python3 -B -m unittest -v`

손계산(가상, 예시용): 1개월 차는 쉬움 20건 중 18건 해결(90%), 어려움 80건 중 40건 해결(50%)이라 전체 (18+40)/100=58%. 3개월 차는 쉬움 80건 중 68건(85%), 어려움 20건 중 8건(40%)이라 전체 (68+8)/100=76%. 난이도별 해결률은 둘 다 떨어졌는데 전체는 58%에서 76%로 올랐다. 1개월 차 구성(쉬움 20%, 어려움 80%)을 3개월 차 해결률에 적용하면 0.85x0.2+0.40x0.8=0.17+0.32=0.49, 곧 49%.

본문이 언급하는 논문 값: Pareek 외(2026)는 참가자 12명의 한 번의 세션을 해석한 질적 관찰이다. 본문의 스스로 점검 1번(가상): (9+20)/50=58%.

기대 출력:
```
[1개월 차] 전체 해결률 58%, 쉬움 90.0%(비중 20%), 어려움 50.0%(비중 80%)
[3개월 차] 전체 해결률 76%, 쉬움 85.0%(비중 80%), 어려움 40.0%(비중 20%)
[2] 1개월 차 구성으로 맞춘 3개월 차 해결률 49.0% (1개월 차 전체 58%)
[3] 최소 열로 답할 수 있는 질문 2/6, 전체 열로 6/6
```

확인하지 못하는 것: 난이도 두 칸으로만 나눴고 난이도를 누가 어떻게 정하는지는 정하지 않았다. 구성을 맞춘 값(49%)은 한 가지 보정일 뿐이고 AI 덕분인지 다른 이유인지는 이 기록으로 알 수 없다. 비교 대상(도입 전 기간이나 쓰지 않는 팀)이 없다. 칸마다 20건과 80건이라 우연의 폭은 계산하지 않았다.
