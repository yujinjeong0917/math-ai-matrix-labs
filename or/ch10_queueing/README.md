# 10장. 이용률을 올리면 왜 대기가 폭증할까

상담원 1명, 평균 처리 5분, 도착이 무작위인 M/M/1 모형의 공식값과 Lindley 점화식 시뮬레이션(seed=7, 20만 건)을 대조합니다. 평균 체류 시간이 목표를 지켜도 30분을 넘기는 고객이 얼마나 되는지, 처리 시간이 일정할 때 대기가 절반이 되는 이유(Pollaczek-Khinchine 식)도 봅니다. 숫자는 학습용 가상값입니다.

```bash
python3 queueing.py
python3 -m unittest -v
```

## 기대 출력(요약)

- 이용률 0.5, 0.7, 0.8, 0.9, 0.95에서 평균 체류 10.0, 16.7, 25.0, 50.0, 100.0분
- 이용률 0.8에서 30분 초과 비율 공식 0.301, 시뮬레이션 0.310
- 평균 체류 30분을 맞추는 이용률 0.833에서도 30분 초과 비율 0.368

## 이 실습이 확인하지 못하는 것

- 상담원이 여러 명인 경우(M/M/c), 시간대별 도착률, 포기·재시도, 우선순위 처리는 다루지 않습니다. 12장에서 시뮬레이션으로 다룹니다.
- 체류 시간 꼬리 공식은 선착순(FCFS)일 때만 맞습니다.
- 평형 상태(오래 돌렸을 때)의 값이므로 개점 직후 같은 짧은 구간에는 그대로 쓸 수 없습니다.
