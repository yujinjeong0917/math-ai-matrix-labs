# 11장. 얼마를 쌓아 둘까

가상 숫자로 세 가지를 계산하고 전수 탐색·시뮬레이션과 대조합니다.

1. EOQ(경제적 주문량): 연 수요 2,400개, 주문 1회 30,000원, 개당 연 보관비 1,200원
2. 뉴스벤더(한 번만 발주하는 시즌 상품): 판매가 36,000원, 매입가 28,000원, 남은 재고 처분가 4,000원, 수요 평균 100개·표준편차 30개(정규분포)
3. 안전재고: 주간 수요 평균 100개·표준편차 30개, 입고까지 2주

```bash
python3 inventory.py
python3 -m unittest -v
```

## 기대 출력(요약)

- EOQ 346.41개, 연 비용 415,692원. 정수로 훑어도 346개
- 임계비율 0.25, 뉴스벤더 최적 79.77개(정수 탐색 80개). 평균인 100개로 발주하면 80개보다 기대이익이 약 77,906원 낮음
- 안전재고 69.79개(서비스 수준 95%), 재주문점 269.79개. 시뮬레이션 달성률 0.950
- 수요 표준편차를 30으로 가정했는데 실제 45이면 달성률 0.864

## 이 실습이 확인하지 못하는 것

- 수요가 정규분포라는 가정, 수요가 시간에 따라 안 변한다는 EOQ 가정, 입고 기간이 고정이라는 가정은 실제 데이터로 확인하지 않았습니다.
- 수량 할인, 최소 주문 수량, 창고 용량, 여러 상품 공동 발주는 다루지 않습니다.
- 안전재고의 달성률은 "주기마다 품절이 없을 확률"이고, 품절 개수 기준 서비스 수준과는 다릅니다.
