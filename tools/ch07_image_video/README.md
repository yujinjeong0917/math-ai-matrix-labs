# 7장. 영상·이미지 도구는 무엇이 다를까 (`ch07_image_video`)

웹 챕터: `math-ai-matrix/tracks/tools/07-image-video.html`

관통 프로젝트(가상의 작은 팀이 만드는 "주간 고객 문의 요약 보고서")에서, 보고서와 팀 공지에 붙일 15초 설명 영상과 표지 그림을 만들 때 값이 어떻게 나오는지 네트워크·API 키 없이 계산한다.

1. 공식 문서에서 옮긴 가격·스펙표(초당 값, 한 번에 만드는 길이, 확장, 해상도, 소리, 출처 표시, 약관)를 날짜가 붙은 파일로 둔다.
2. 15초를 모델이 허락하는 길이로 채우는 방법(한 번에 / 확장 / 조각 이어 붙이기)과 과금 초를 구한다.
3. 마음에 들 확률 p(가정값)로 "마음에 드는 1개를 얻을 때까지 최대 k번 뽑기"의 기대 비용, 성공 확률, 90%를 넘기는 k를 분수로 정확히 계산하고 몬테카를로로 대조한다.
4. 숫자 하나짜리 "그림"으로 잡음 제거(확산) 장난감을 돌려, 시드가 결과를 정하고 단계가 적으면 흐릿한 평균에 머문다는 것을 본다.

## 실행
```bash
uv run python tools/ch07_image_video/experiments.py   # results/ch07.json 갱신
uv run pytest -q tools/ch07_image_video
```
표준 라이브러리만 쓴다(fractions, math, random). 실제 API를 부르지 않는다.

## 파일
| 파일 | 역할 |
|---|---|
| `tools_ch07_cost.py` | 가격표 읽기, 15초 채우기(plan_clip), 뽑기 기대 비용·성공 확률·k 찾기, 조각 다시 뽑기, 몬테카를로, 이미지 장당 값 |
| `tools_ch07_diffusion.py` | 1차원 잡음 제거 장난감(정방향 섞기, 두 점 데이터의 정확한 평균 추정, DDIM 방식 역방향, 경계 찾기) |

| `data/prices_2026-10-10.json` | 가격·스펙·약관표. 항목마다 출처 URL과 확인일. 값이 바뀌면 날짜가 다른 새 파일을 만든다 |

## 가격을 바꿀 때
`data/prices_YYYY-MM-DD.json`을 새로 만들고 `tools_ch07_cost.PRICE_FILE`을 그 파일로 바꾼 뒤 실험과 테스트를 다시 돌린다. OpenAI Sora 2 API처럼 도구가 통째로 없어지는 경우(2026-09-24 종료)도 있어 파일 이름에 날짜를 넣었다.

## 한계와 가정
- 마음에 들 확률 p(1/10, 1/4, 1/2)는 정한 값이다. 실제 p는 `checks/ch07.csv`에 뽑기마다 기록해 세어야 한다. 뽑기마다 p가 같고 서로 독립이라고 둔다.
- Veo 3.1 확장 7초는 새로 만든 7초만큼 낸다고 가정했다(문서에서 확인 못함).
- 이어 붙인 조각의 이음매가 자연스러운지, 확장이 원하는 대로 이어지는지는 계산하지 않는다.
- 차단·실패로 생성되지 않은 영상은 Veo 문서상 청구되지 않는다. "마음에 안 듦"은 청구된다. 둘은 다르다.
- Gemini Omni Flash는 한 번에 만드는 길이 선택지를, Runway Gen-4.5는 소리 생성 여부를, Kling은 약관과 눈에 안 보이는 표시를 공식 문서에서 확인하지 못했다.
- 잡음 제거 장난감은 학습이 없다. 데이터가 두 점(-1이 75%, +1이 25%)뿐이라 신경망 대신 정확한 평균 추정을 식으로 쓴다.

확인일 2026-10-10.
